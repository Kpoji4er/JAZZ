# JAZZ 0.20-6224

Комплект из четырёх модов: JAZZ, JAZZ-assets, JAZZ-maps и JAZZ-units. Архивы собраны из зафиксированных коммитов, локальные незакоммиченные изменения исключены.

## Изменения

- На Легионе (`JAZZ_Legion_*`) надетые жилеты и замапленные шлемы видны на теле; жилет EOD больше не называется Flak M69.
- Убран прототип `SpecOpsBody`: риг непригоден. Тестовый юнит `JAZZ_Legion_SpecOpsTest` снят.
- Кабинет модификации оружия больше не падает с assert на `JazzGetOwnerUnit`.
- Стационарные пулемёты: конус на полную `WeaponRange`, угол 45°.
- Исправления инвентаря (idContainer на портретах, пустой магазин, чипы) и сектор MaxRange станков, вошедшие после 0.20-6220.

## Проверка и ограничения

- Статические проверки items.lua/metadata.lua и mock-тесты визуала брони Легиона прошли. Editor/runtime приёмка брони на теле остаётся открытой.
- Общая проверка GitHub Quality gates по спецификациям по-прежнему рекомендательная: незакрытые AC не считаются принятыми этим выпуском.
- CommonLib main проверен: 1.11, build 1067, commit a1a5f4819d60b4d410d515f926ef45646c6989e7. CommonLib не включён в архивы.

## Установка

Использовать все четыре пакета из одного выпуска. Не включать JAZZ-maps и JAZZ Vanilla Maps одновременно. JA3 запускать через Steam.

Прямые ссылки (обновляются этим выпуском):

- Комплект: https://github.com/Kpoji4er/JAZZ/releases/latest
- Playable ZIP: https://github.com/Kpoji4er/JAZZ/releases/download/playable/jazz-playable.zip
