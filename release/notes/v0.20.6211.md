JAZZ **0.20-6211** — first versioned GitHub suite release (Ernie demo).

Install all four zips into `Mods/` plus the latest **JA3_CommonLib**. Do not use Code → Download ZIP (LFS maps/art can be missing).

### This cut
- Salvage one bandage or morphine → **1 Meds** (stack −1). Kits unchanged.
- Flare gun **Signal Flare** button works again; default slot stays fists.
- Vicki repairs weapon/armor **resource**, not vanilla Condition %.
- Overwatch cone narrows with distance; interrupt is a CTH penalty.
- L6 Ernie caches stay island-tier (not mainland mine diamonds) — new game for that loot.
