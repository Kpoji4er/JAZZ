# JAZZ 0.20-6230 — prerelease

Собраны все локальные изменения оружия, брони, UI, локализации и инструментов, включая параллельную работу в основной копии.

- 1739 иконок точных конфигураций оружия: исходные размеры ячеек, цвет по прежним игровым иконкам и тёмная обводка. Для Desert Eagle и Hi-Power сглажена тональная коррекция.
- Отключённые AR15, M4Commando и MP5 исключены из набора. Неотснятые сочетания модулей используют прежнюю иконку; полное покрытие всех сочетаний ещё не заявлено.
- Включены актуальные исправления моделей оружия, креплений, Carry Handle, названий конфигураций Мосина и визуалов брони Легиона, включая кожаный плитник.
- Сохранены ранее опубликованные обновления портретов и настройки стартового тира/скорости прогрессии новой игры.
- Крупные исходники сохранены через Git LFS. Временные каталоги, Blender-файлы и архивы исходников исключены из игровых ZIP.

Проверено: выбор и fallback иконок (5281 сценарий), все 1739 установленных PNG, generated-data graph четырёх пакетов (0 ошибок, 29 предупреждений по неактивным/старым данным), целостность активных ассетов, Lua short strings, отсутствие новых циклических wraps, документация, статические модели стрельбы и AI crowd scoring. Исправлен разбор ModItem независимо от отступов и однострочной сериализации.

**Ограничение prerelease:** полный запуск нового комплекта, загрузка сохранения, игровой осмотр последних иконок/моделей и editor round-trip после объединения не выполнены. Открытая игровая приёмка HAV/6Б3 и замечания по моделям не объявляются закрытыми. В собранной истории есть старые пробелы/пустые строки; массовое форматирование runtime-файлов не выполнялось.

Для визуальных исправлений новая игра не требуется. Стартовый тир и скорость прогрессии выбираются при создании новой игры. Профиль комплекта: CommonLib + assets + units + maps + jazz; Vanilla Maps остаётся отдельной альтернативой maps.

CommonLib: 1.11, build 1067, проверенный upstream `a1a5f4819d60b4d410d515f926ef45646c6989e7`. Точные SHA, версии пакетов и SHA-256 находятся в приложенном manifest и SHA256SUMS.

Спасибо Kpoji4er, FruBayun и Doctorleevsy; авторство исходных коммитов сохранено в истории проекта.
