# JAZZ 0.20-6227 — обновлённые портреты наёмников

Предварительный выпуск / Prerelease. Не помечен как latest.

Обновлены 12 пар Portrait/BigPortrait: BarrySeal, Spouke, Conrad, Nervous, Ira, Laura, Meat, Lucky, Vilde, Blade, Henning и Steiger. Уточнены лица и взрослые пропорции, уменьшена искусственная волнистость одежды, очищены края. У Конрада исправлена поза. Маленькие портреты заново кадрированы из соответствующего полного изображения.

24 PNG: UI 300×300, Big 2000×2000, RGBA. Исходники генерации 1254×1254, Big увеличены. Пути, ID, характеристики, перки и модели персонажей не изменялись. Экспериментальная модель Blender не включена. Новая игра для портретов не нужна.

## Проверки и ограничения

- Проверены размеры, RGBA, визуальное кадрирование и прозрачные края; structural items/metadata checks и локальная документация.
- Generated sync: ошибок связности нет; strict отмечает два предупреждения времени файлов — metadata изменена для Revision/changelog, items.lua не менялась.
- Live JA3 UI, новая игра, save/load и editor round-trip не проверены. Местами остаётся тонкая искусственная фактура ткани.
- Состав основан на опубликованном origin/main; локальная незавершённая работа по оружию и броне не включена.
- Общий GitHub Quality gates падает на ранее существовавших ссылках документации вне этого изменения; предыдущий опубликованный commit также имеет красную проверку. Локальная проверка четырёх изменённых страниц прошла.
- Units CI: те же 81 ошибки generated companion, что на предыдущем опубликованном Units commit; список сравнён, новых ошибок нет. Локальный legacy-аудитор не обнаруживает эти companions и не заменяет CI.
- Сохраняются ограничения предыдущего prerelease 0.20-6226.
