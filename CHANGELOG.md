## [0.20-6211] — 2026-09-01

Первый versioned GitHub Release комплекта. Состав: `jazz` `0.20-6211`, `jazz_assets` `0.02-649`, `jazz-maps` `1.07-5150`, `jazz-units` `0.19-2327`. Поддерживаемый проход — остров Эрни.

### Медицина и инвентарь

- Разбор одного полевого бинта или морфина даёт **1 Meds** в сумке отряда (стек −1). Аптечки без изменений. Массового разбора нет.
- Полевые бинт/морфин тратят AP по Medical; аптечки стабилизируют травмы, а не лечат их как полевой бинт.
- Kits в бою лечат до текущего max HP; потолок травмы падает после боя.

### Бой и оружие

- Сигнальная ракета снова отдельная кнопка **Signal Flare**; слот по умолчанию — кулак. У `FlareGun` восстановлены `ValidatePos` / `GetAttackResults`.
- Перк Vicki чинит `WeaponResource` / `ArmorResource` по часу, не ванильный процент `Condition`.
- Конус Overwatch сужается с дистанцией; tint только в прицеливании; interrupt — штраф CTH, не бонус.
- Шанс броска гранаты от Strength+Dex+Explosives; сила расширяет круг.
- Пулемёты после эффективной зоны падают к 25% точности; магазин на трупах NPC ограничен сложностью.
- Энергия (Free Move) и травмы ног/рёбер влияют на ход и усталость.

### ИИ

- Животные (крокодилы/гиены) используют ванильный боевой ИИ и бьют ближайшего врага.
- Один wrap на бросок гранаты ИИ — без переполнения стека.
- Высота, FallBack, dump через воздух, медики и поддержка до штурма.
- Боевые окрики (видимые враги, паника, гранаты) с лимитом.

### Стратегия и карты Эрни

- Схроны L6 — островной тир, не материковые алмазы шахты.
- Возмездие майора и денежные конвои по под-тирам Легиона.
- K2 — авторская прибрежная карта «Старая ретрансляционная башня».

### Интерфейс

- Две строки hotbar (24 слота): Take Cover и Overwatch остаются видимыми.
- Заголовок в Mod Manager больше не содержит зашитый номер версии.

### Известные ограничения

- За Эрни контент ещё в разработке; после крупных срезов рекомендуется новая игра.
- В этой сессии не было live DAP-проверки Signal Flare и разбора бинта/морфина (есть static).
- С российских провайдеров GitHub assets часто требуют VPN; без VPN — Steam Workshop.

## [0.11-5938] — 2026-07-26

Снимок `main` @ `335c19f` (+ этот changelog и сопутствующая technical-документация).

### Бой и оружие

- Мультипликативная модель стрельбы / CTH (`AccuracyRangeCTH`, связанный UI crosshair).
- Падение урона от дистанции и ребаланс оружия.
- Абилки по классам оружия (в т.ч. до боевых винтовок), правки пулемётов и миномёта.
- Трейты авто- и тяжёлого оружия; абилка «Побег с отвлечением».
- Точечные hotfix CTH/UI и particle fallback для взрывов.

### ИИ и стратегия

- Удалены сторонние AI-политики `Rato_*` из load path; зафиксирован контракт собственной AI-системы.
- Пилот глобального AI Легиона для I7 / guardpost patrols (`Guardpost_Patrols`, Regions/POI).
- Уточнены совместимость и override-матрица для strategy/AI пересечений.

### Локализация

- Исправлены ID локализации; добавлен английский перевод поверх поддержки русского.
- Контракт и skill локализации обновлены под репозиторный CSV.

### Процесс и tooling

- AI-first документация комплекта, quality gate docs, Discord-сводки изменений по push в `main`.
- Suite package gate и проверка целостности assets (`check-asset-integrity`).
- Явное одобрение перед `git push` в agent skills.
- Каталог квестов/локаций/врагов Эрни; канон боевого авто вынесен в JAZZ Maps.
- Заметки по crocodile patrol (shipping без `debug`) и smoke для `CampCrocodile_CirclingPatrol`.
- J7 «Изумрудный берег» в каталоге: `Label1=Ernie`, music Ernie_*, без `InitialSquads` (враги на карте / RescueHerMan).

### Зависимости

- Объявленная зависимость CommonLib в metadata: `version_major`/`version_minor` **1.11** (поддерживается только актуальный upstream `main`).

### Известные ограничения

- Играбельное демо — остров Эрни; материк в данных не считается поддерживаемым прохождением.
- Assert `goEntityPersist.cpp: cmp` на старте при Ignore обычно безопасен; Lua/runtime ошибки — нет.
- Дубликат `MapVar("gameOverState")` может дать игнорируемый assert `(not table.find(MapVars, name))`.
