## Контракт с wiki

Technical-раздел отвечает на вопросы «где и как реализовано», wiki — «что это делает и как этим пользоваться». При изменении игровой механики:

1. Обновить профильную техническую страницу.
2. Обновить соответствующий гайд в `../wiki/`.
3. Проверить, что формулировки не противоречат друг другу.
4. В wiki не переносить нестабильные внутренние IDs и детали кода, если они не нужны игроку.

CommonLib всегда проверяется по текущему upstream `main`; указанные version/build/commit являются только датированным снимком аудита.
