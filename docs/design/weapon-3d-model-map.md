# Оружие → 3D-источники и credit

Аналог `armor-3d-model-map.md` для оружейных мешей. Здесь фиксируются архив-источник, автор, требуемое упоминание и то, что из пака реально берётся. Исходные архивы неизменны, распаковка только во временную папку вне репозиториев.

Канон масштаба: линейка АК-ремастера, ≈ 0.87 от реальной длины (`docs/design/weapons-import-plan-jaweapons.md`, «АК ≈ 0.9 м»). Перед импортом — оверлей с принятым АК в одной сцене, side + top.

Канон нарезки модулей: только целые связные части (loose parts). Плоскостной разрез запрещён — `JAZZ-WEAPON-AK-FAMILY-001-AC-001` уже был отклонён владельцем именно из-за разреза, пересекавшего губки магазина и пистолетную рукоять.

## Где упоминать автора

1. Обязательно: строка в этой таблице (repo-layer).
2. Решение владельца по игроковому слою (описание мода в `metadata.lua`, Steam-страница) — отдельным вопросом; на 2026-09-19 секции credits в описании нет.
