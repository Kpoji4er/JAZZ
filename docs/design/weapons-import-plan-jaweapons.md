# План импорта оружия из `<WEAPON_SOURCE_ROOT>` (список владельца)

Источник списка: `<WEAPON_SOURCE_ROOT>\weaponslist.txt`. Это **план-очередь**, а не разрешение на работу.
Старый `docs/design/weapons-import-queue.md` — история СР-3М/Мосин/АК/L42, **не** текущий todo.

Первоначально очередь велась по одному стволу на чат. Прямое решение владельца 2026-09-23
«делай все сразу», затем «проверь и импортируй сразу» разрешает пакетный проход.

Уточнение владельца 2026-09-23: проверку материалов выполнить **по всему списку сразу**.
Источники без материалов/текстур — **REJECT**, не создавать им материалы с нуля.
Полный входной аудит: [weapons-material-audit-jaweapons.md](weapons-material-audit-jaweapons.md),
машинные доказательства — одноимённый JSON. Наличие карт без MTL допускает восстановление
назначений, но не означает готовность источника к импорту. Существующие ремодели и замены
не откатывать из-за брака первоначального архива. Игру пока не запускать.

Итог полного прохода по 51 источнику: 41 с отдельными текстурами, 3 GLB со встроенными
материалами/изображениями, 3 REJECT, 4 REVIEW из-за отсутствия UV на части мешей.
**REJECT:** `9A-91 Assault Rifle Gameready Lowpoly.zip`, `Izhmash AK-103.zip`,
`Just A Hatchet.zip`. Это отклонение данных архивов, не существующего AK103 из другого источника.
**REVIEW:** `PP-91-01 Kedr-B.zip` (model_2), `HK416.zip` (model_17),
`FN SCAR Rifles.zip` (model_39), `Mk 12 Special Purpose Rifle.zip` (11 OBJ без UV).
Остальные допускаются к следующему этапу проверки, но ещё не приняты для игрового импорта.
Для Kiparis/Pecheneg MTL содержит только константы, без привязок карт; отдельные текстуры есть.
У PKM лишь две карты (`_g`, `_s`); назначение каналов требует проверки, полный PBR-комплект не подтверждён.

### Результат импорта исходников — 2026-09-23

[Полный batch-отчёт](weapons-import-batch-results.md), spec `JAZZ-WEAPON-BATCH-IMPORT-001`.
Из 51 источника: 28 импортированы с назначенными материалами/UV и без оставшихся ошибок
mesh-аудита; 18 импортированы в review с нерешёнными назначениями/UV/геометрией; 4 REJECT;
M240 остановлен как дубль MG58 (дополнительно Blender не читает FBX 6100).
Новый **REJECT Mk12 SPR**: проверка показала отсутствие UV на корпусе, прикладе, магазине,
цевье и стволе; материалы есть лишь у отдельных аксессуаров. Его диагностическая сцена сохранена.
Для Кедра-Б восстановлены карты корпуса/глушителя, но model_2 без UV остаётся исключённым
из готовности к экспорту. HK416/SCAR — локальные no-UV детали, не повод отклонять весь комплект.
Все сцены: `Weapons/_batch_jazz_import/<номер_источник>/clean/Source.blend`.
**Это не установка оружия в JA3**: assembly, игровой масштаб, rig/spots, HGE export,
регистрация согласованных данных и editor/runtime-приёмка остаются следующими этапами.

## Обязательный контур на каждый ствол

| Гейт | Требование |
| --- | --- |
| Исходник | не трогать; копия в `Weapons/_<slug>_jazz_build` |
| Blend | `clean/<Weapon>.blend` + `rigged/<Weapon>_JA3.blend` (Origin-empty + HGE spots + модули-entity, не Bip001) |
| Оси | Blender −Y вперёд, метры; HGM (−Y,−X,Z); FBX `axis_forward='Y'`, `axis_up='Z'`, FBX_SCALE_ALL, MESH+EMPTY |
| Масштаб | оверлей с принятым АК в одной сцене (side + top, длины в метрах) **до** импорта; длинный ствол ≥ АК; `scale=0.8` — только СР-3М |
| Grip | нет пистолетной рукояти → `ModifyRightHandGrip = true` в `InventoryItem/<ID>.lua` **и** `items.lua`; эталон `Mosin.lua` |
| Holster | винтовка/ПП/дробовик → `Shoulder`; пистолет → `Leg` |
| Иконка | 324×165 с тёмной обводкой (эталон `WeaponIcons/AK74.png`, `AKM.png`) |
| Аттачи | CPU PNG по образцу `_build_ak_attachment_fit_scene.py`, left+right, оптика +top |
| Spots | Muzzle, Barrel, Trigger, Hand_l_grip, MuzzleTip; по модулям Magazine/Stock/Handguard/Under/Bipod; планка Scope/Mount/General |
| Spec | `docs/specs/active/JAZZ-WEAPON-<ID>-001.md`, `$specify-jazz-change`, DoR до реализации |
| Generated data | `items.lua` + `metadata.lua` + companion — одна транзакция (`$sync-jazz-generated-data`) |
| Текстуры | после импорта `$rename-jazz-weapon-textures` (numeric DDS → `<Entity>_<Suffix>.dds`) |
| Bobby | явный вердикт `in` (Tier/RW/MaxStock/Cost/CategoryPair) или `out` + причина — `jazz-bobby-ray-new-items.mdc` |
| Локализация | `$manage-jazz-localization`, RU/EN |
| Нормали | никогда custom/split; `prepare_export_mesh`; успешный exporter ≠ PASS; `python docs/tools/_check_mesh_export_normals.py` |
| Проверки | `_check_weapon_imports.py`, размер иконки, grip-флаг, длина vs АК |
| Скрипты | `_build_<slug>_assets.py`, `_integrate_<slug>.py` остаются в `docs/tools/` + строка в `docs/tools/README.md` |

## Иконки: что проверять

Все `WeaponIcons/*.png` в пакете уже 324×165 — проверено по IHDR: `AK74`, `AKM`, `AK74M`, `AK105`,
`SR3M`, `L42A1`, `Mosin`. Размер не является отличием «хорошей» иконки от «плохой», спорить надо про **контур**.
PowerShell `System.Drawing` врёт на этих файлах (выдаёт 512×256); мерить через Pillow или сырой IHDR.

Объективные ориентиры по `AK74.png` / `AKM.png`:

- содержимое (alpha bbox) ≈ 295×105 при холсте 324×165, то есть ~92% ширины;
- дуло вправо, приклад влево;
- средняя яркость кольца обводки на фоне `#2a2a2a` ≈ 26–27 при фоне 42, то есть контур **темнее** фона.

Проверка: `_compose_icon_review.py` даёт лист «на шахматке / на #2a2a2a / эталоны на том же фоне».
