## Проблема

На новой сетке у регулярной армии почти нет своих секторов. В разговоре: «одна база с Фошо и всё», плюс форт; Легион и пустые клетки занимают карту. Игрок не чувствует армию как третью силу ни на сателлите, ни на тактике.

Цель черновика: **Адонис, Легион и армия различаются и на глобалке, и на тактичке.**

## 1. Присутствие армии на карте

- В **каждом регионе** — хотя бы одна армейская база.
- Вокруг базы — посты; в ближайших секторах встречаются военные (патрули / гарнизоны / случайные встречи — уточнять позже).
- Базы можно раскидать по всей карте; пустых клеток много, пустынный биом ~20–25 клеток, реки и каналы (правый низ) дают место под посты и водные части.
- Уже заложенные якоря (не назначение, только что есть в атласе): `A13`, `P26`, подземка Фошо у `L16`. Остальные регионы (Эрни, Ла-Барьер, Великий лес, Флитаун, Какао, Горная степь, пустыня…) — дыры.

Не цель этого абзаца: сразу включать Army Global AI уровня Легиона.

## 2. Дипломатия и доступ игрока (до раскрытия заговора)

Пока заговор не раскрыт (в текущем контракте это **World Flip** / `04_Betrayal`):

- Вояки **как будто** воюют с Легионом.
- На деле **нейтральны ко всем**, включая игрока. (014 уже фиксирует нейтрал Army→player до Flip и мир Adonis↔Army; «воюют с Легионом» на sat — отдельный director, сейчас partial.)
- Игрок **не заходит** на армейские сектора свободно. Исключения: квесты и скриптовые бои (как сейчас с повстанцами).
- После Flip враждебность уже описана в 014; закрытые базы / «можно ли штурмовать штаб Фошо только сюжетно» — открытый вопрос.

## 3. Подразделения и спавн с баз

Черновые типы (из заметок, не roster):

| Тип | Заметка |
| --- | --- |
| Регуляры | базовая пехота, обычные базы |
| Морпехи / «речпехи» | преимущественно по воде / рекам / каналам |
| ВДВ / авиадесант | см. шорткат-вертолёт ниже |
| Разведка | лёгкие встречи вокруг баз |
| Спецназ | отдельные базы / высадки |
| Ополчение | местные, слабее регуляров |

Правило: **разная база → разный тип** спавна. Не одна каша `ArmySoldier` со всех точек.

В `jazz-units` уже есть Regular / Special / Special Forces и `ArmySpecOps` — это задел составов, не привязка к секторам и не водный/десантный director.

## 4. Продажный лейтенант

Отдельный контакт, не штаб Фошо:

- продаёт оружие, связан с наймами;
- игрока сводят миссиями;
- у него **своя база**, которую можно дать «в управление» (смысл: союзный/серый форпост, не захват всей армии).

Стык с будущим ECON-003 (квестовый NPC-магазин) — возможный, не обязательный. Имя/сектор не выбраны.

## 5. Транспорт и шорткаты

Общая мысль: узкие реки «вплавь» неудобны; ваниль уже решает часть воды через **shortcut**. Каналы город↔город — быстрый путь **или** пешком. Железка у Corlo уже в набросках карты; аэродромы/самолёты/вертолёты тоже заложены как способы, не как runtime.

### 5a. Реки и каналы

- Узкие реки → shortcut (как ваниль где-то делает), не полноценный «заплыв» по каждой клетке.
- Каналы в правом нижнем квадранте: быстрый ход между городами vs обычный маршрут берегом.

### 5b. ВДВ / вертолётный отряд (AI)

1. Аванпост (или база) создаёт **шорткат** к точке высадки.
2. Отряд-вертолёт летает туда и обратно по этому шорткату.
3. Тянет с собой отряды спецназа / ВДВ.
4. **Игнорирует** все сектора между базой и точкой и все гарнизоны на пути.
5. На точке высадки десант становится **обычным** sat-отрядом.

### 5c. Железная дорога (игрок)

- Тоже через shortcut.
- Условие: **обе** станции (отправка и прибытие) под контролем игрока.

### 5d. Вертолёт и самолёт игрока

| Средство | Черновое правило |
| --- | --- |
| Вертолёт | как лодка, но игнор всех секторов кроме клетки прибытия (ориентир JA2) |
| Самолёт | строго аэропорт → аэропорт |

Не путать с уже живущим HMMWV: тот едет **только по дорогам** и не игнорит промежуточные сектора.

## Что это не трогает (пока)

- Не меняет locked матрицу 014 без отдельного решения (закрытые сектора до Flip — **новое** ограничение поверх нейтрала).
- Не обещает Army director уровня Легиона.
- Не описывает тактический бой в вертолёте/самолёте/поезде.
- Не назначает конкретные ID баз по регионам.
