# Партия бронежилетов: очередь производства

Рабочий список для последовательного производства собственных Torso-мешей (JAZZ-APPEAR-001).
Назначение — не перечитывать весь контекст на каждый предмет. Контур пайплайна остаётся в
`.agents/docs/playbooks/legion-armor-modeling.md`; эталон кода — `docs/tools/_model_legion_armor.py`.

Статус партии: Фаза 0 закрыта. `JazzArmor_6B3` установлен как `JAZZ_6B3_Male` + тестовый юнит; runtime/human приёмка открыта. Остальные предметы не начаты.

## Общие свойства партии

Все 16 предметов: `Slot` по умолчанию `Torso` (поля `Slot` в их `InventoryItem` нет),
appearance-часть `parts.Armor` / Origin, `class_parent` = `CharacterArmorMale`.
Штатный Body не подменяется. Female, Legs и шлемы в эту партию не входят.

Собственной entity нет ни у одного. В `jazz_assets/Entities` из брони сейчас только
кираса, Chainmail, Tire*, Twaron/Guardian/Zylon и SpecOpsBody.

Бюджет геометрии от эталона: кираса `11 528` tri при `6030` исходных вершинах.
Рабочая норма Torso ~12k tri, потолок ~16k. Фактический счёт меряется после обрезки донора,
а не по заявленному числу автора.

Карта `docs/design/armor-3d-model-map.md` для этой партии источником доноров **не является**:
её строки назначают IBA/UHMWPE/Spectra/SWAT нарезкой HAV, то есть тем же мешем, который уже
носят Twaron/Guardian/Zylon.

## Колоризация

Предметы этой партии красятся через `SetColorizationMaterial`, как уже сделано для ванильных
Flak/Interceptor в `Code/System_LegionArmorVisuals.lua`. Официальный контракт
(`ModTools/Docs/ModItemEntity.md.html`): маска колоризации помечает до четырёх частей строго
чистыми `#ff0000`, `#00ff00`, `#0000ff` и нулевой альфой, смешение на границах запрещено, а
Base Color красящихся частей должен быть серым в диапазоне 190–220. Число частей задаётся
свойством «Number of masked colors in CM» в Haemimont Material.

Каналы 6Б3: C1 — чехол, C2 — подсумки и карманы, C3 — стропы и фурнитура. В `clean` blend
принадлежность каждой части записана в custom property `hg_colorization`.

Следствие: серый Base Color означает, что строка mapping **обязана** задавать цвета, иначе
предмет будет выглядеть белёсым. Значения по умолчанию (олива): C1 `RGBA(74, 82, 48)`,
C2 `RGBA(58, 65, 38)`, C3 `RGBA(46, 50, 31)`.
