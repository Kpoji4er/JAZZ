# Тестовые сборки оружия из локального архива

Решения владельца от 15 сентября 2026. Корень источников — локальный архив `Weapons`, не игровой runtime.

1. **СР-3М** — ввод непосредственно в `jazz` + `jazz_assets`, spec `JAZZ-WEAPON-SR3M-001`. Корпус, цевьё, магазин, дульная часть, складываемый приклад. Собран и добавлен, локальные статические проверки проходят; игровая проверка ещё не выполнена. Тестовая роль — тяжёлый ПП Т3 (под-тир 3-2), выбор ПП/карабин остаётся предварительным по последнему уточнению владельца. Урон 32, дальность 26, магазин 30, выстрел/перезарядка 4/5 AP, отдача 20. Звуки и FX пока через AK74; фактическое воспроизведение включить в игровые проверки.
2. **L42A1** — следующий тест, источник `Sniper/L42A1 Sniper Rifle`. Минимальная модульность по дизайну старой винтовки, собственный родной прицел. В источнике два OBJ, отсутствуют оба заявленных MTL, есть PNG-карты 4096; требуется восстановление материалов и проверка состава геометрии прицела. Звуки/FX — подходящая болтовая винтовка.
3. **Мосинка — разрешена к реализации последующим сообщением владельца.** Источники `Sniper/Mosin Nagant 1891.zip`, `Sniper/Mosin–Nagant M38.zip`, `Sniper/Mosin Nagant _Obrez_.zip`. Один предмет с вариантами Barrel: 1891, M38, Obrez. Обрез — уникальная конфигурация этого слота, одновременно без полноценного приклада; меньше AP на выстрел, лучше ближний профиль навскидку, хуже aim и дальность. Рабочие сцены и восстановленные материалы созданы отдельно от исходников; игровая интеграция ещё не выполнена.
4. **Семейство АК — разрешено к реализации, после основных сборок.** Источники `Weapons/AK`. Ремастер АК-74 и АКМ, новые АК-74М и АК-105. Единые совместимые магазины внутри семейства 5.45x39 (30 и 45), аналогичная совместимость внутри 7.62x39. Магазины 40/75 для 7.62 — предложенные варианты, наличие геометрии и пригодность ещё проверяются. Допустимо использовать подходящие ванильные модели. Между калибрами совместимости нет.

Приоритет имеет задача «Изучить мод JAZZ» (`01a0a1cc-71ac-7a70-9a61-7aacc57928ac`). При пересечении уступить ей общие файлы, exporter/editor и runtime; в ожидании можно работать с изолированными исходниками. Последнее поручение владельца «делай все» снимает прежнюю оговорку о выполнении АК только при остатке токенов.

Текущие DDS в `jazz_assets/Entities/Textures` до новых импортов: 909 файлов 1024², 168 — 512², 134 — 2048², 50 — 4096²; остальные прямоугольные или меньшие. АС-ВАЛ/G3A4 — 1024²; UMP45/CZ75/AA52 — 2048²; FG42 Base/Normal — 4096×2048. Fallbacks преимущественно 64².
