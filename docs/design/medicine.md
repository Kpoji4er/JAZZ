# Медицина и ранения JAZZ (design draft)

Статус: **черновик дизайна**, не approved spec и не current-state.  
Связанный current-state: [armor-damage-wounds-will.md](../technical/systems/armor-damage-wounds-will.md).  
Будущий контракт реализации: ожидаемый `docs/specs/active/JAZZ-MED-001` (ещё не заведён).

## Цель

Жёсткий бой не должен выталкивать в F5 через смерть мерка. Цена ошибки — **долг на глобалке**: статусы, выпадение из ротации на дни, нагрузка на несколько рабочих групп.

## Хотим / не хотим

**Хотим**

- Кровотечение — по тяжести (лёгкое / тяжёлое). Раны — **лёгкая / средняя / тяжёлая**.
- Раны снимают ОД; **Обезболивание** отменяет −ОД от ран, на которые оно действует, пока висит.
- Лёгкие раны **сходят сами** через несколько ходов.
- Средние раны: шанс **только если уже есть лёгкая** рана; долг на глобалке.
- Тяжёлые раны **не купируются** и выдаются **только при ноке** мерка.
- Кровотечение давит в бою и на глобалке; может добить. Шанс с **любого попадания**; наличие ран повышает шанс (тяжелее рана → выше).
- Средние/тяжёлые раны и переломы лечатся на глобалке.
- Полевое лечение запускает медленное заживление; качество ускоряет.
- Госпиталь снимает долг **по окончании** операции.
- Нок вместо лёгкой смерти мерка от HP=0.
- Компактный инвентарь: стаки + 1–2 кита.

**Не хотим**

- Тарков с предметом на каждый дебаф.
- Отдельный POI «полевой госпиталь» — это операция лечения отряда.
- Перманентные ампутации до конца кампании как обычный исход (narrative-трейты — редко).
- Месяц out after нока / выезд на большую землю.
- Сброс долга уходом из сектора.
- **Grit на старте боя** (сейчас `GritOnStart.lua` ≈ 25% Health как Temp HP) — **отменяем**.
- Вешать `Tired` / усталость отдыха с травм (рёбра и т.п.) — усталость = другой скоуп.

## Система ранений / статусы

### Что есть сейчас (чтобы не тащить кашу дальше)

| ID | Фактически | Проблема |
|---|---|---|
| `Armsshot` / `Legsshot` / `Headshot` / `Torsoshot` / `Groinshot` | Одноходовые скрытые роллеры → шанс повесить вторичный эффект | Не ранения, а триггеры; часть `RemoveOnEndCombat`, часть нет |
| `Wounded` | Стаки: −max HP, −AP; ролл на `Bleeding`; операция | Нет лёгкая/средняя/тяжёлая; схлопывание с другими статусами |
| `Bleeding` | Стаки, урон/ход, CTH, AP на 3 стеках; тик и вне боя | Нет различия обычное/тяжёлое; бинт/bandage снимает без эшелонов |
| `Inaccurate` / `Slowed` | Штрафы CTH / move AP; сходят роллом по ходу/часу; operation heal снимает | Неясно: бой или долг; дублируют будущий перелом/контузию |
| `Blinded` / `Numbness` / … | Вторичка от head/arms | Ок как **лёгкие боевые**, не как долг |
| `BleedingOut` | Отдельный near-death | Связать с политикой нока |
| Grit (`GritOnStart`) | Temp HP ~25% Health на старте боя | Целевой дизайн: **убрать** |

Целевой дизайн ниже **не обязан** сохранить все ID 1:1; маппинг — в конце секции.

### Слои (канон)

Четыре слоя (+ grit out). Попадание **роллит** слой; `*shot` не бейдж.

```text
Попадание (пробита броня / нет покрытия)
  → шанс кровотечения (база + бонус от уже висящих ран: лёгкая < средняя < тяжёлая)
  → ролл по части тела + тяжести хита
      ├─ Лёгкая рана (−ОД; сама через N ходов)
      ├─ Средняя рана (только если уже есть лёгкая)
      ├─ Перелом
      └─ Шок

Нок мерка
  → тяжёлая рана (не купируется; дальше сильно поднимает шанс крови с хитов)
```

#### A. Кровотечение (острое) — по тяжести

Стакается **внутри** своего уровня. Урон тиками **в бою и на глобалке**.

| Тяжесть | Эффект (ориентир) | Кто снимает |
|---|---|---|
| **Лёгкое** | Меньший урон/тик; стаки наращивают давление | Бинт, IFAK, мед. аптечка |
| **Тяжёлое** | Сильнее тик; сильнее штрафы; опаснее на карте | Только IFAK / мед. аптечка (**бинт не лечит**) |

**Источник:** шанс появиться от **любого попадания** (при пробитой броне / без покрытия — как у прочих физ. статусов).  
Раны на цели **повышают** этот шанс: чем тяжелее висящие раны, тем выше. Ориентир модификаторов (числа позже):

| Состояние цели | Вклад в шанс крови |
|---|---|
| Нет ран | базовый шанс с хита |
| Лёгкая рана | + |
| Средняя рана | ++ |
| Тяжёлая рана | +++ |

Несколько ран/стаков складывают вклад (кап — баланс). Тяжесть самой крови (лёгкая vs тяжёлая) — отдельный ролл/порог (часть тела, урон, крит и т.п.), не то же самое, что «шанс появиться».

Правила:

- Лёгкое и тяжёлое кровотечение — разные состояния. Эскалация крови — отдельный ролл/событие, не авто с N стаков (если порог понадобится — явно).
- Не снятое едет на карту и продолжает давить.
- Кровь **не** обязана рождаться из OnAdded раны: рана только крутит шанс на следующих хитах (и на том же хите, если рана уже висела / успела наложиться — порядок роллов уточнить в реализации).
- Числа — баланс позже.

#### B. Рана (`Wounded`) — три тяжести

**Штраф:** раны снимают **ОД** (за стак / по тяжести — числа позже).  
**Обезболивание** — пока действует, отменяет −ОД от ран, на которые действует (лёгкая и средняя; **не** тяжёлая). Стаки не снимает.

| Тяжесть | Откуда | Lifetime / долг | −ОД | Обезболивание | Снятие |
|---|---|---|---|---|---|
| **Лёгкая** | Хит в бою | Сама сходит через **несколько ходов** | да | глушит −ОД | Сама / конец таймера; не долг госпиталя |
| **Средняя** | Хит, **только если уже есть лёгкая** рана | Долг: не сходит сама за бой | да | глушит −ОД | Глобалка: полевая → заживление; госпиталь → по концу |
| **Тяжёлая** | **Только нок** мерка | Долг на карте | жёстче | **не действует** | Глобалка: медленнее; госпиталь → по концу; хирургия ускоряет |

Правила:

- Три разных состояния; могут сочетаться (лёгкая + средняя и т.д.).
- Средняя **не** роллится без активной лёгкой на цели в момент хита.
- Тяжёлая **не** с обычного хита и **не** эскалация «набралось средних».
- Лёгкая — тактический налог на ОД; средняя — цена продолжать получать урон уже раненым; тяжёлая — цена нока.
- Кровь — отдельный слой A: шанс с любого хита; раны повышают шанс (тяжелее → выше), но не «рана = авто-кровь» из OnAdded.
- Ретрит не снимает среднюю/тяжёлую. Лёгкая: если таймер не истёк к концу боя — **сбрасывается с концом боя** (не тащим «полхода лёгкой» на карту), если баланс не решит иначе.
- Бинт раны не трогает.

#### Grit (отмена)

Текущий runtime: `GritOnStart.lua` выдаёт Temp HP ≈ **25% Health** на старте боя.  
В целевой модели медицины / живучести: **Grit на старте боя отменяем** (не выдаём). Буфер «бесплатных» 25% HP уходит; давление ран/крови/нока читается честнее.
#### C. Перелом (структурный долг, по зоне)

Не «ещё один inaccurate навсегда», а **отдельный долг** с зоной:

| Зона | Типичный штраф |
|---|---|
| Руки | CTH / обращение с оружием |
| Ноги | Move AP / скорость |
| Торс / рёбра | **−старт ОД**; **забирает Free Move**; опц. +move cost / no sprint |
| Голова | не перелом в v1 → контузия / травма глаза |

- Получение: ролл с хита по зоне (пробитие), отдельно от ран; шанс может расти, если уже есть средняя/тяжёлая рана (уточнить).
- Бой: купирование IFAK / мед. аптечкой (шина внутри кита, не отдельный предмет). Обезболивание — **не** обязательно глушит перелом (открытый вопрос; по умолчанию **нет**, только −ОД ран).
- Карта: заживление после полевой / снятие в госпитале; хирургия ускоряет.
- Бинт не трогает.

#### D. Боевые дебафы (короткие)

Короткие статусы. Не долг госпиталя. Не предмет на каждый.

| Дебаф | Откуда | Суть | Lifetime |
|---|---|---|---|
| **Контузия** | Голова, близкий взрыв, **взрыв под ногами** | см. ниже | 1–2 хода |
| **Оглушение (слух)** | Взрыв / близкий выстрел | Слышимость (± CTH); не vision | Коротко |
| **Сбит прицел** | Руки / шок | −CTH | Коротко |
| **Затруднённое движение** | Ноги / шок | +move AP | Коротко |
| **Ослепление вспышкой** | Flashbang / короткий head-proc | Sight + CTH | 1–2 хода |
| **Онемение** | Руки | Слить в «сбит прицел», если нет уникального эффекта | Коротко |

##### Контузия (в т.ч. взрыв под ногами)

Источники: голова, близкий взрыв, **взрыв в клетке / соседней (под ногами)**.

Пакет эффекта:

| Эффект | Зачем |
|---|---|
| **−ОД на следующий ход** (или до конца текущего) | Главное: «оглушило» |
| **−CTH** умеренный | Дезориентация |
| **Нельзя sprint / +move AP** | Особенно для взрыва под ногами |
| Тяжёлый ролл | Редко prone или нок |

Не делать: полный stan каждый раз; перма-долг; отдельный предмет «от контузии».  
Вспышка (sight) ≠ контузия (ОД/CTH/move): под ногами — в основном контузия без обязательного blind.

##### Перелом рёбер / торса (слой C)

| Эффект | Зачем |
|---|---|
| **−старт ОД каждый ход** | Дышать больно; ≠ руки/ноги |
| **Нет Free Move** (статус забирает / блокирует получение) | Резкое перемещение бьёт по рёбрам; читаемо в бою |
| Опц.: +move AP / нельзя sprint | Дополнительная нагрузка без ухода в Tired |
| Опц.: +шанс крови с торс-хитов | Синергия с A |

**Не** накладывать `Tired`. Рёбра = ОД + **без Free Move**, не шкала отдыха.  
Не дублирует −max HP раны. Обезбол по умолчанию не глушит; IFAK/аптечка могут вернуть Free Move / ослабить −ОД в бою; снятие — глобалка/госпиталь. Заживает дольше перелома руки.

##### Ожоги — долг после `Burning` (**да**)

Активный `Burning` = контур E (тушить / уйти).  
После снятия горения (или огненного хита) — **ожоговая травма** (долг):

- В бою: −ОД и/или слабый тик (слабее крови).
- На карте остаётся; **заживает дольше** средней раны при том же качестве лечения.
- Бинт не лечит; аптечка может ослабить тик, не снять долг; полевая → медленное заживление; госпиталь → по концу.
- Отдельный канал от раны B («сгорел» ≠ «пуля»). Не перма до конца кампании.

##### Blind — разделить

| Вид | Слой | Лечение |
|---|---|---|
| Вспышка | D | Сама |
| Газ | E | Маска / уйти |
| Травма глаза | долг | Заживление / госпиталь |

Правила D: только бой; не пачкой в TreatWounds; обезбол по умолчанию не снимает D.

#### Кандидаты в травмы (что ещё имеет смысл)

Фильтр: новый статус ок, только если даёт **новый канал поведения**, а не пятый способ −CTH. Предмет под статус — нет.

| Кандидат | Вердикт | Зачем / почему нет |
|---|---|---|
| Перелом рук/ног | **да, v1** | Слой C |
| Перелом рёбер / торса | **да** | −старт ОД + **нет Free Move**; без Tired |
| Травма глаза (долг) | **да, рассмотреть** | ≠ flashbang / газ |
| Оглушение слуха | **да, рассмотреть** | Взрывы ≠ vision |
| Контузия | **да** | −ОД след. ход + −CTH + no sprint; взрыв под ногами |
| Растяжение / вывих | **нет** | Дубль |
| Внутреннее кровотечение | **нет** | = тяжёлая кровь |
| Ожоги (долг после Burning) | **да** | Дольше средней раны; бинт не лечит |
| Инфекция | **нет в v1** | Симуляторно |
| Отравление | **вне ран** | Свой контур (если появится) |
| Потеря крови / «анемия» после тяжёлого bleed | **опц. позже** | Временный −max HP на карте после стабилизации крови |
| Челюсть / речь | **нет** | Мало геймплея в JA3 |
| Ампутация / выбитый глаз навсегда | **нет** | Уже anti-goal; только narrative-трейт |
| Паника от крови (hemophobic) | **уже трейт** | Не общая травма |
| «Шок от боли» отдельным статусом | **нет** | Покрыто −ОД ран + обезболом |

**Компактный целевой набор травм (рекомендация):**

```text
Кровь (лёгкая/тяжёлая)
Раны (лёгкая/средняя/тяжёлая)
Перелом (руки / ноги / рёбра)
Ожог (долг после Burning, долгое заживление)
Травма глаза (редко)
Короткий D: контузия (в т.ч. взрыв под ногами), вспышка, слух, inaccurate, slowed
Среда E: газ-blind, активный Burning, choking
```

Всё остальное либо слить, либо отложить.

#### E. Вне медицины ран

| Контур | Примеры | Почему отдельно |
|---|---|---|
| Подавление / воля | `suppression*`, `Pinned` | Will Points |
| Среда | `Burning`, `Choking`, **газ-blind**, погода | Тушение / маска / выход из зоны |

### Купирование vs снятие

| | Купирование (бой) | Снятие |
|---|---|---|
| Лёгкая кровь | — | бинт / IFAK / аптечка |
| Тяжёлая кровь | — | только IFAK / аптечка |
| Лёгкая рана (−ОД) | **Обезболивание** глушит −ОД | Сама через N ходов (не госпиталь) |
| Средняя рана (−ОД) | **Обезболивание** глушит −ОД | Глобалка (заживление / госпиталь) |
| Тяжёлая рана | **не купируется** | Глобалка (медленнее; госпиталь; хирургия) |
| Перелом | IFAK / аптечка / обезболивание (уточнить) | Глобалка |
| Шок | обезболивание / аптечка / сам | конец боя / тики |

Обезболивание не снимает рану и не глушит тяжёлую.

| Сейчас | Целевой слой | Заметка |
|---|---|---|
| `*shot` | Ролл при хите | Не бейдж |
| `Wounded` | Лёгкая (таймер) / средняя (нужна лёгкая) / тяжёлая (нок) | Убрать авто-bleed из OnAdded; раны дают **мод шанса** крови на хитах |
| `Bleeding` | Лёгкая / тяжёлая кровь | Шанс с любого хита; тяжесть ран ↑ шанс |
| (нет) | **Обезболивание** | −ОД лёгкой и средней |
| `GritOnStart` / Temp HP 25% | **Удалить** | Нет grit на старте боя |
| `Inaccurate` / `Slowed` | Шок или перелом | |
| `BleedingOut` | Нок → ещё тяжёлая рана | |

`HealWounds` / operation heal пачкой — нельзя: кровь отдельно; лёгкая не доживает до операции; средняя/тяжёлая → заживление, не мгновенный remove на полевой.

## Смерть и нок

1. HP ≤ 0 в бою у мерка → **нок**, не мгновенная смерть.
2. При ноке мерк получает **тяжёлую рану** (слой B) — единственный штатный источник тяжёлых ран.
3. Смерть — узкий набор: добивание нокнутого / кровотечение без помощи на карте / явный сюжетный кейс.
4. После нока: ориентир **несколько дней** до возврата в строй (не месяц), в том числе из‑за тяжёлой раны. Точные ETA — баланс.

## Предметы

Все применения медицины: **self + ally**.

| Предмет | Формат | Навык | Эффект |
|---|---|---|---|
| **Бинт** | Стак, одноразовый; крафт из `Meds`; распространённый лут | Минимальный / почти 0 | Снимает / снижает **лёгкое** кровотечение. **Не** лечит тяжёлую кровь. Не хилит HP, не купирует раны/перелом |
| **Морфий** | Расходник (стак) | **Не нужен** | **Обезболивание** на N ходов: глушит −ОД **лёгких и средних** ран. Не глушит тяжёлые. Не кровь, не HP |
| **IFAK** | Кит, **10 зарядов**, рефил из `Meds` | Medical | Кровь в т.ч. тяжёлая; купир перелома; короткое обезболивание (уточнить) |
| **Медицинская аптечка** | Кит, заряды + `Meds` | Выше Medical | Кровь + **хил HP** + обезболивание / перелом |
| **Хирургический набор** | Редкий, тратится | Высокий на карте | **Глобалка:** ускоряет заживление средних/тяжёлых. **Тактика:** длинное обезболивание до конца боя (лёгкие+средние); тяжёлые не купируются |

### Инвентарный паттерн

Типичный боец в рейде: стак бинтов + морфий + **одна** кита (IFAK или мед. аптечка).  
Хирургический набор — у врача отряда / на складе сектора, не у каждого.

### Анти-обесценивание

- Бинт → только лёгкая кровь.
- Тяжёлая кровь → IFAK/аптечка; тяжёлая рана → только нок, без купирования.
- Средняя рана → только поверх лёгкой; морфий глушит −ОД, не снимает долг.
- **Без Grit 25%** на старте — живучесть через броню/позиционирование/медицину, не бесплатный буфер.

## Глобалка: две двери

Отдельный POI «полевой госпиталь» **не вводим**.

| Дверь | Что это | Исход для тяжёлого |
|---|---|---|
| **Полевое лечение** | Операция отряда на карте (`TreatWounds`-like): `Meds` + Medical | Стабилизация (кровь/HP) + **запуск медленного заживления** тяжёлого |
| **Госпиталь** | Hospital POI / стационар | По **окончании** операции тяжёлые статусы **сняты** |

Врачи с высоким Medical (ориентир ≥ 70) улучшают качество полевого лечения (быстрее последующее заживление).  
Апгрейд «полевое → стационар Пауком» в v1 не обязателен: сильный врач усиливает полевую фазу; стационар = другой исход.

## Фазы раны / перелома

```text
Бой (хит)
  → лёгкая рана (−ОД, таймер N ходов) и/или кровь / перелом / шок
  → если уже есть лёгкая → шанс средней раны (долг)
  → обезболивание глушит −ОД лёгкой и средней

Лёгкая рана
  → сходит сама через N ходов (или с концом боя)

Нок
  → тяжёлая рана (без купирования)

Полевая операция
  → кровь/HP стабилизация
  → средняя/тяжёлая/перелом → заживление на карте (средняя быстрее тяжёлой)

Госпиталь
  → по концу — средние/тяжёлые раны и переломы сняты
```

## Переломы

Детали слоя C выше. Кратко: зона → разный штраф; в бою только купирование; снятие на глобалке; бинт не трогает. Отдельный лут «шина» не вводим.

## Антипаттерны

- Предмет на каждый дебаф.
- Два типа госпиталя-POI.
- Снятие перелома / тяжёлой крови / средних или тяжёлых ран бинтом.
- Купирование тяжёлой раны морфием / аптечкой.
- Выдача тяжёлой раны обычным хитом; выдача средней без лёгкой.
- Тащить лёгкую рану на глобалку как долг госпиталя.
- Оставлять Grit 25% Temp HP на старте боя.
- Долгие `Inaccurate`/`Slowed` как замена перелому + пачковый heal с кровью.
- Показ `*shot` как отдельное ранение на бейдже.
- Месяц out после каждого нока.
- Обычный бой → ампутация до конца кампании.
- Медицина только на self.
