# Медицина и ранения JAZZ (design draft)

Статус: **approved**; v1 implementing — [JAZZ-MED-001](../specs/active/JAZZ-MED-001.md).  
Связанный current-state: [armor-damage-wounds-will.md](../technical/systems/armor-damage-wounds-will.md).  
Зональные травмы (Arms/Legs/Ribs/Head + Burn stub) — **в scope MED-001**. Госпиталь clear / инфекция / отдельный Eye ID → MED-002+.

## Цель

Жёсткий бой не должен выталкивать в F5 через смерть мерка. Цена ошибки — **долг на глобалке**: статусы, выпадение из ротации на дни, нагрузка на несколько рабочих групп.

## Хотим / не хотим

**Хотим**

- **Боль** = самостоятельный дебаф (−ОД, −CTH); −1/ход, растёт от юза зоны / тяжёлой травмы. Морфий глушит боль.
- **Лёгкая травма** = только боль при юзе, без специфика зоны. Средняя+ = боль + специфик.
- Кровотечения **стакаются** (несколько лёгких + среднее и т.д.); бинт улучшает один стак на −1 тир за юз.
- Средние/тяжёлые раны и переломы лечатся на глобалке.
- Полевое лечение запускает медленное заживление; качество ускоряет.
- Госпиталь снимает долг **по окончании** операции.
- **Болевой шок** (боль/нагрузка → без сознания) и **геморрагический шок** (много крови → коллапс/умирание).
- Компактный инвентарь: стаки + 1–2 кита.

**Не хотим**

- Стаки `Wounded` от потерянных HP.
- Отдельный POI «полевой госпиталь» — это операция лечения отряда.
- Перманентные ампутации до конца кампании как обычный исход (narrative-трейты — редко).
- Месяц out after нока / выезд на большую землю.
- Сброс долга уходом из сектора.
- **Grit на старте боя** (сейчас `GritOnStart.lua` ≈ 25% Health как Temp HP) — **отменяем**.
- Вешать `Tired` / усталость отдыха с травм (рёбра и т.п.) — усталость = другой скоуп.

### Слои (канон)

Четыре слоя (+ grit out). Попадание **роллит** слой; `*shot` не бейдж.

```text
Попадание (пробита броня / нет покрытия)
  → шанс кровотечения (база + бонус от уже висящих ран: лёгкая < средняя < тяжёлая)
  → ролл по части тела + тяжести хита
      ├─ Лёгкая рана (−ОД; сама через N ходов)
      ├─ Средняя рана (только если уже есть лёгкая)
      ├─ Перелом
      └─ Шок

Нок мерка
  → тяжёлая рана (не купируется; дальше сильно поднимает шанс крови с хитов)
```



#### A. Кровотечение — три тяжести + естественный ход

Не только «лёгкое / тяжёлое», а **лёгкое → среднее → тяжёлое** с тиками урона и **роллами перехода** (если не лечить предметом).


| Тяжесть     | ОЗ/стак/ход | Чем снимают / снижают                        |
| ----------- | ----------- | -------------------------------------------- |
| **Лёгкое**  | **3**       | Бинт → снимает этот стак. IFAK/аптечка тоже  |
| **Среднее** | **6**       | Бинт → лёгкое. IFAK/аптечка сильнее          |
| **Тяжёлое** | **12**      | Бинт → среднее. IFAK/аптечка снимают/сильнее |


Бинт за применение улучшает **один стак** на **один тир** вниз (приоритет худшему стаку). Несколько стаков = несколько бинтов или кит. IFAK/аптечка дороже по ОД, но сильнее (снять стак / несколько).

Стаки **разрешены**: на юните может висеть сразу несколько кровотечений, например **3 лёгких + 1 среднее**.

**Источник появления (с хита):**


| Тир крови   | Откуда                                                                                                                                                                        |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Лёгкое**  | **Высокий** шанс с **любого** попадания (пробитие / нет покрытия)                                                                                                             |
| **Среднее** | **Низкий** шанс с обычного попадания (отдельно от лёгкого; не обязательно через эскалацию)                                                                                    |
| **Тяжёлое** | **Только от экспансивных** боеприпасов (HP / JHP и аналоги по данным патрона). Обычная FMJ/AP тяжёлую с хита не вешает — только через ухудшение среднего по таблице переходов |


Раны на цели дополнительно ↑ шанс крови (лёгкая < средняя < тяжёлая рана).  
Можно получить сразу среднее редким роллом; сразу тяжёлое без экспансива — нет.  
Шея/крит могут крутить шанс лёгкого/среднего, но не заменяют правило «тяжёлое с хита = только экспансив».

##### Переходы (если висит и не сняли предметом)

Ролл раз в ход в бою и раз в фиксированный интервал на глобалке (например час / тик сателлита — число позже).

**Твой вариант (сырой):**


| Сейчас  | Исход ролла                  |
| ------- | ---------------------------- |
| Лёгкое  | 80% сходит · 20% → среднее   |
| Среднее | 50% → лёгкое · 50% → тяжёлое |
| Тяжёлое | 20% → среднее · 80% остаётся |


Минус среднего 50/50: без лечения кровь **быстро уезжает в тяжёлую** (каждый тик монетка). Для «надо постараться сдохнуть» это жестковато, если ролл частый.

**Рекомендуемый вариант (стабильнее, тот же дух):**


| Сейчас  | Сходит / лучше    | Без изменений    | Хуже               |
| ------- | ----------------- | ---------------- | ------------------ |
| Лёгкое  | **70%** сходит    | 15% остаётся     | **15%** → среднее  |
| Среднее | **35%** → лёгкое  | **45%** остаётся | **20%** → тяжёлое  |
| Тяжёлое | **15%** → среднее | **85%** остаётся | — (само не сходит) |


Идея: лёгкое часто само; среднее — зона решений (бинты уже слабо, нужен IFAK или риск); тяжёлое почти не отпускает само — давление чистить китом.

**Модификаторы к таблице (важно):**

- Рядом / в отряде хороший Medical → сдвиг к «лучше / сходит» (как пассив у инфекции, слабее).
- В бою под огнём / после нового хита → сдвиг к «хуже».
- BeingBandaged / только что бинтовали → форс-улучшение или пропуск ролла ухудшения.
- На глобалке в госпитале / на полевой операции переходы заморожены или только улучшение.

**Урон за тик (принято):** за **один стак**, за ход в бою. На глобалке — тот же порядок за сателлит-тик (или реже — только частота ролла, не урон). Сейчас в runtime было 5×стаки одной крови.


| Тир         | ОЗ / стак / ход | Ощущение на мерке ~80 HP          |
| ----------- | --------------- | --------------------------------- |
| **Лёгкое**  | **3**           | ~4%/ход; 3 лёгких = **9**/ход     |
| **Среднее** | **6**           | ~7.5%/ход                         |
| **Тяжёлое** | **12**          | ~15%/ход; с хита только экспансив |


Примеры: 3 лёгких + 1 среднее = **15**/ход; 1 тяжёлое + 2 средних = **24**/ход.  
С полных ~80 без лечения: 1 лёгкое ≈ 25+ ходов · 3 лёгких ≈ 9 · 1 среднее ≈ 13 · 1 тяжёлое ≈ 7.

**Кап** суммарного урона крови за ход — ориентир **30** (чтобы гора стаков не ваншотила); точное число — плейтест.

Стаки **разрешены**: на юните может висеть сразу несколько кровотечений, например **3 лёгких + 1 среднее**.


| Правило        | Как                                                                                                                                 |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Урон/тик       | Сумма по всем стакам (лёгкий×N + средний×M + тяжёлый×K)                                                                             |
| Новый хит      | Может добавить ещё один стак нужного тира (не обязательно заменять)                                                                 |
| Переходы       | Ролл **по каждому стаку** (или по одному случайному за тик — баланс); ухудшение/улучшение двигает этот стак                         |
| Бинт (−1 тир)  | Улучшает **один** стак за применение: приоритет худший (тяжёлый → средний → лёгкий → снят). Три лёгких = три бинта, чтобы снять все |
| IFAK / аптечка | За одно применение снимает **все** стаки крови любого тира и восстанавливает ОЗ; аптечка лечит на **50%** сильнее                  |


Кап стаков на тир / суммарный кап — баланс (чтобы не умереть от десяти лёгких за один бой без шанса).

#### B. Боль (`Pain`) — самостоятельный дебаф

Не часть «ранения» и не абстрактный `Wounded`. Отдельный стакающийся дебаф.


|                            |                                                                                        |
| -------------------------- | -------------------------------------------------------------------------------------- |
| **Что даёт**               | **−ОД** и **−точность (CTH)** — от стаков боли                                         |
| Тик вниз                   | **Каждый ход −1** стак (если не поднимали); **в конце боя** все стаки снимаются (`RemoveOnEndCombat`) |
| Рост                       | **Попадание с уроном** **+1** Pain (не graze); юз зоны: Light **+1** / Medium **+2** / Heavy **+3** (раз/зону/ход); unused Heavy **+1**/ход за зону |
| **Обезболивание** (морфий) | Сразу **снимает** Pain и блокирует набор, пока Analgesia; один раз возвращает ОД, уже удержанные Pain в начале текущего хода; специфик травмы остаётся |
| Бинт                       | Боль не снимает                                                                        |



| Травма              | Когда боль растёт                            | Стаки Pain |
| ------------------- | -------------------------------------------- | ---------- |
| **Ноги**            | Передвижение (sprint сильнее)                | Light 1 / Medium 2 / Heavy 3 |
| **Руки**            | Выстрел / перезарядка / бросок / interact    | Light 1 / Medium 2 / Heavy 3 |
| **Рёбра**           | Sprint / нагрузка / старт хода               | Light 1 / Medium 2 / Heavy 3 |
| **Глаз**            | Прицеливание / атака (опц.)                  | (→ Head) |
| **Ожог**            | Действия или слабый фон (уточнить)           | Light 1 / Medium 2 / Heavy 3 |
| **Тяжёлая** (любая) | Если зону в этот ход **не** юзали — +1/ход   | +1 за каждую unused Heavy |


Лежишь с больной ногой — боль сама падает. Побежал — снова растёт.

##### Шоки (да, в модели)

**Болевой шок**  
Если боль упёрлась в кап / резко взлетела от нагрузки на травме (типичный кейс: **спринт / много движения на ногах или тяжёлой травме**) — шанс упасть в **без сознания** (нок/Unconscious).  
«Пробежал — отключило» — читаемый риск; не каждый шаг, а порог+ролл (числа позже). Морфий снижает риск, пока глушит боль.

**Геморрагический шок**  
Набрал **много кровотечений** (сумма стаков / суммарный урон крови за короткое окно / кап стаков) — коллапс: переход в **критическое / умирание** (рядом с `BleedingOut` / нок).  
Это «поймал кучу крови — упал умирать», не то же самое, что тик лёгкого бинтуемого стака. Лечение: срочная остановка крови (IFAK/аптечка) + стабилизация; бинтами по одному стаку можно не успеть.

Оба шока — редкие жёсткие исходы, не постоянный фон. Точные пороги — баланс.

#### C. Конкретные травмы (вместо `Wounded +N`)

Абстрактные стаки ранения от HP — **нет**. Травма зоны: лёгкая / средняя / тяжёлая.

**Формула:** травма = источник боли + (со **средней**) специфик зоны.  
Морфий убирает боль временно; специфик остаётся.


| Тир         | Специфик зоны                                            | Боль    | Заживление                                         |
| ----------- | -------------------------------------------------------- | ------- | -------------------------------------------------- |
| **Лёгкая**  | **Нет** — только боль при юзе зоны                       | +1 при юзе | **Может зажить сама**                              |
| **Средняя** | Заметный специфик + боль при юзе                         | +2 при юзе | После полевой → легче со временем                  |
| **Тяжёлая** | Жёсткий / небоеспособный + боль при юзе / пассив unused  | +3 при юзе; +1/ход если зона не юзалась | После лечения слабеет медленнее; госпиталь снимает |


Так нет двойного штрафа на лёгкой: лёгкая рука ≠ −CTH зоны + боль; только боль от стрельбы. Средняя рука = −CTH зоны **и** боль (морфий глушит второе).


| Зона | Средняя (специфик) | Тяжёлая |
|---|---|---|
| **Руки** | сильный −CTH / дороже стрельба | почти не стреляет |
| **Ноги** | сильно +move / no sprint | почти не ходит; max satellite slow |
| **Рёбра** | −старт ОД + нет Free Move | критический −ОД; out |
| **Голова / глаз** | −sight/−CTH / контузия-хвост | почти слепой / небоеспособный; **с хита в голову часто сразу средняя/тяжёлая** |
| **Ожог** | долгий долг | тяжёлый долг + инфекция |
| **Нок** | — | пакет тяжёлой травмы + боль |


Получение с хита по зоне. Несколько травм вместе ок. Травмы ↑ шанс крови.

**Броня зоны ↓ шанс травмы:** если на юните надета броня с `ProtectedBodyParts` для этой зоны (руки→Arms, ноги→Legs, рёбра→Torso/Groin, голова→Head/Neck) и Condition > 0 — пороги ролла травмы масштабируются вниз (до ~×0.4 при высоком Coverage и целости). Это смягчение — для **пробитых** / прошедших `*shot`. Ожог и нок-пакет не режутся этой бронёй.

**Заброневое (BAT):** попадание в зону, где броня **остановила** пулю (`armor_decay`, нет `armor_pen`) — крови и обычных `*shot` нет, но ролл **заброневой** травмы: шанс лёгкой (редко средней) травмы этой зоны. Боль: при остаточном уроне — общий **+1** с попадания; при полном поглощении — `JazzAddPainStacks(1)` в BAT. Шанс растёт с «энергией» удара (`armor_prevented` + остаточный урон). Непробитая броня больше не делает зону «иммунной» к травме — только к кровотечению и пробитым эффектам.

**Голова:** повышенный шанс получить сразу **среднюю или тяжёлую** травму (не обязательно через лёгкую). Тяжёлая с головы — редко, но заметно опаснее торса/конечностей. Лёгкая с головы тоже возможна. Параллельно часто короткий D (контузия / вспышка).

Остальные зоны: чаще стартуют с лёгкой; среднее/тяжёлое — реже с хита или через ухудшение / нок.

Бинт травмы не лечит. `Wounded` HP-стек — **deprecated**.

#### Grit (отмена)

`GritOnStart` (~25% Temp HP) — **убираем**.

#### D. Боевые дебафы (короткие)

Короткие статусы. Не долг госпиталя. Не предмет на каждый.


| Дебаф                     | Откуда                                      | Суть                                                | Lifetime |
| ------------------------- | ------------------------------------------- | --------------------------------------------------- | -------- |
| **Контузия**              | Голова, близкий взрыв, **взрыв под ногами** | см. ниже                                            | 1–2 хода |
| **Оглушение (слух)**      | Взрыв / близкий выстрел                     | Слышимость (± CTH); не vision                       | Коротко  |
| **Сбит прицел**           | Руки / шок                                  | −CTH                                                | Коротко  |
| **Затруднённое движение** | Ноги / шок                                  | +move AP                                            | Коротко  |
| **Ослепление вспышкой**   | Flashbang / короткий head-proc              | Sight + CTH                                         | 1–2 хода |
| **Онемение**              | Руки                                        | Слить в «сбит прицел», если нет уникального эффекта | Коротко  |




##### Контузия (в т.ч. взрыв под ногами)

Источники: голова, близкий взрыв, **взрыв в клетке / соседней (под ногами)**.

Пакет эффекта:


| Эффект                                           | Зачем                          |
| ------------------------------------------------ | ------------------------------ |
| **−ОД на следующий ход** (или до конца текущего) | Главное: «оглушило»            |
| **−CTH** умеренный                               | Дезориентация                  |
| **Нельзя sprint / +move AP**                     | Особенно для взрыва под ногами |
| Тяжёлый ролл                                     | Редко prone или нок            |


Не делать: полный stan каждый раз; перма-долг; отдельный предмет «от контузии».  
Вспышка (sight) ≠ контузия (ОД/CTH/move): под ногами — в основном контузия без обязательного blind.

##### Рёбра / ожог (уточнения к тирам C)

- **Рёбра:** без `Tired`; средняя = −ОД + нет Free Move; тяжёлая = небоеспособный по ОД.  
- **Ожог:** после активного `Burning`; тиры как у травм; заживает долго; может → инфекция; бинт не лечит.



##### Blind — разделить


| Вид          | Слой | Лечение                |
| ------------ | ---- | ---------------------- |
| Вспышка      | D    | Сама                   |
| Газ          | E    | Маска / уйти           |
| Травма глаза | долг | Заживление / госпиталь |


Правила D: только бой; не пачкой в TreatWounds; обезбол по умолчанию не снимает D.

#### Кандидаты в травмы (что ещё имеет смысл)

Фильтр: новый статус ок, только если даёт **новый канал поведения**, а не пятый способ −CTH. Предмет под статус — нет.


| Кандидат                                     | Вердикт        | Зачем / почему нет                                  |
| -------------------------------------------- | -------------- | --------------------------------------------------- |
| Перелом / травма по зоне                     | **да**         | Тиры лёгкая/средняя/тяжёлая (небоеспособный)        |
| Рёбра                                        | **да**         | Средняя: −ОД + no Free Move; без Tired              |
| Травма глаза                                 | **да**         | Тиры; ≠ flashbang / газ                             |
| Ожог                                         | **да**         | Тиры; долго; может → инфекция                       |
| Контузия / слух                              | **да**         | Короткий D, не «травма-долг»                        |
| Растяжение отдельным                         | **нет**        | = лёгкая травма ног/рук                             |
| Внутреннее кровотечение                      | **нет**        | = тяжёлая кровь                                     |
| Инфекция                                     | **да**         | Пассивный контур (см. E)                            |
| Отравление                                   | **вне ран**    | Свой контур (если появится)                         |
| Потеря крови / «анемия» после тяжёлого bleed | **опц. позже** | Временный −max HP на карте после стабилизации крови |
| Челюсть / речь                               | **нет**        | Мало геймплея в JA3                                 |
| Ампутация / выбитый глаз навсегда            | **нет**        | Уже anti-goal; только narrative-трейт               |
| Паника от крови (hemophobic)                 | **уже трейт**  | Не общая травма                                     |
| «Шок от боли» отдельным статусом             | **нет**        | Покрыто −ОД ран + обезболом                         |


**Компактный целевой набор травм (рекомендация):**

```text
Кровь ×3 тира (стаки; бинт −1 тир одному стаку)
Боль (стаки; −CTH/−ОД; морфий глушит)
Конкретные травмы × зона × тир (не Wounded-от-HP)
Короткий D + среда / инфекция
```

Всё остальное либо слить, либо отложить.

## `HealWounds` / operation heal пачкой — нельзя: кровь отдельно; лёгкая не доживает до операции; средняя/тяжёлая → заживление, не мгновенный remove на полевой.



## Смерть и нок

1. HP ≤ 0 в бою у мерка → **нок**, не мгновенная смерть.
2. При ноке мерк получает **тяжёлую конкретную травму** (и/или сильную Боль) — не стак `Wounded` от HP.
3. Смерть — узкий набор: добивание нокнутого / кровотечение без помощи на карте / явный сюжетный кейс.
4. После нока: ориентир **несколько дней** до возврата в строй (не месяц), в том числе из‑за тяжёлой раны. Точные ETA — баланс.

## Предметы

Все применения медицины: **self + ally**.


| Предмет                 | Формат                                      | Навык          | Эффект                                                                                       |
| ----------------------- | ------------------------------------------- | -------------- | -------------------------------------------------------------------------------------------- |
| **Бинт**                | Стак; крафт из `Meds`; **очень частый лут** | **Не нужен**   | Кровь: **−1 тир одному стаку** (сначала худший). **Мало ОД**                                 |
| **Морфий**              | Расходник (стак)                            | **Не нужен**   | **Обезболивание** + **подъём из downed** (как аптечка, без хила ОЗ / без снятия крови). Не чинит травму. **Мало ОД** |
| **IFAK**                | Стак **5**; один юз = одна штука            | Medical **30** | Восстанавливает ОЗ, стабилизирует downed и снимает **все** кровотечения.                     |
| **Медицинская аптечка** | Стак **3**; один юз = одна штука            | Medical **50** | То же, но восстанавливает на **50% больше ОЗ**.                                              |
| **Хирургический набор** | Редкий, тратится                            | Только врач    | Ускоряет заживление на карте; в бою длинный обезбол                                          |

### Инвентарный паттерн

Типичный боец в рейде: стак бинтов + морфий + **одна** кита (IFAK или мед. аптечка).  
Хирургический набор — у врача отряда / на складе сектора, не у каждого.

### Анти-обесценивание

- Бинт → **−1 тир одному стаку крови** (сначала худший); без навыка; мало ОД; очень частый лут. Три лёгких = три бинта.
- Морфий → обезбол **без навыка**; **мало ОД**.
- Средняя/тяжёлая кровь → IFAK/аптечка; иначе таблица переходов давит сама.
- IFAK доступен с Medical **30**, аптечка — с **50**; порог и нехватка навыка видны отдельной строкой в ролловере.
- Даже при достатке аптечек бинт/морфий выгодны: мало ОД, без skill gate.
- Тяжёлая рана → только нок, без купирования.
- **Без Grit 25%** на старте.

## Глобалка: две двери

Отдельный POI «полевой госпиталь» **не вводим**.


| Дверь               | Что это                                                         | Исход для тяжёлого                                                  |
| ------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------- |
| **Полевое лечение** | Операция отряда на карте (`TreatWounds`-like): `Meds` + Medical | Стабилизация (кровь/HP) + **запуск медленного заживления** тяжёлого |
| **Госпиталь**       | Hospital POI / стационар                                        | По **окончании** операции тяжёлые статусы **сняты**                 |


Врачи с высоким Medical (ориентир ≥ 70) улучшают качество полевого лечения (быстрее последующее заживление).  
Апгрейд «полевое → стационар Пауком» в v1 не обязателен: сильный врач усиливает полевую фазу; стационар = другой исход.

## Фазы раны / перелома

```text
Бой (хит)
  → лёгкая рана (−ОД, таймер N ходов) и/или кровь / перелом / шок
  → если уже есть лёгкая → шанс средней раны (долг)
  → обезболивание глушит −ОД лёгкой и средней

Лёгкая рана
  → сходит сама через N ходов (или с концом боя)

Нок
  → тяжёлая рана (без купирования)

Полевая операция
  → кровь/HP стабилизация
  → средняя/тяжёлая/перелом → заживление на карте (средняя быстрее тяжёлой)

Госпиталь
  → по концу — средние/тяжёлые раны и переломы сняты
```
