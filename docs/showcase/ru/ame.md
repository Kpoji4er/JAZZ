# Африканская биржа наёмников

[К обзору](home.md) · [Наёмники AIM](mercenaries.md) · [English](../en/ame.md)

В PDA появляется отдельный сайт **Африканская биржа наёмников (A.M.E.)** — не вкладка внутри AIM. Окно сайта в **саванновом** тоне (охра/бронза, логотип щита с Африкой) — визуально не путается с AIM/HazOS.

## Суть

- Пул **60** местных бойцов; на витрине сразу около **15** доступных к найму.
- Остальные либо ещё не вышли на рынок, либо ушли (серые карточки: Легион / гибель и т.п.).
- Ротация рынка примерно раз в **30** дней кампании.
- Категории: Новобранцы · Бойцы · Закалённые · Специалисты.
- Свой фиксированный стартовый кит и портрет у каждого; без случайного «ролла» инвентаря при найме.
- Дешевле AIM при сопоставимой роли; специалисты — верх ценника A.M.E., но всё ещё ниже элиты AIM.
- Найм через тот же чат/контракт; **не** съедает лимит контактов AIM.

## Зачем это игроку

Длинная кампания получает массовый локальный кадр для обучения и заполнения отрядов, не дублируя AIM-элит.
