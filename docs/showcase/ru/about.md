# Что такое JAZZ

[К обзору](home.md) · [English](../en/about.md)

## Коротко

**JAZZ** — комплект оверхола для *Jagged Alliance 3*: бой и точность, оружие и компоненты, тактический и стратегический AI, юниты, карты/контент и UI. Четыре мод-пакета работают вместе.

| Пакет | За что отвечает |
| --- | --- |
| `jazz` | Код, предметы, эффекты, UI |
| `jazz_assets` | Модели, материалы, текстуры |
| `jazz-maps` | Карты, квесты, диалоги, сектора |
| `jazz-units` | UnitData, AI-архетипы, отряды, прогрессия |

## Что заметно в игре

- Шанс попадания в обычном UI читается по `+` / `−`, а не по проценту (проценты — только с debug tools).
- Одиннадцать стрелковых классов с разными ролями; тиры сравнивают силу *внутри* класса.
- Классовые и специальные боевые действия поверх базовых режимов огня.
- На Эрни отряды Легиона на стратегии показывают **роль** и **задачу** (гарнизон, патруль, вербовщик, сборщик налогов, QRF и др.).

## Чем эта витрина является

Двуязычная **витрина**: аспекты мода с конкретной игроковой механикой. Страницы публикуются из репозитория и обновляются вместе с правилами.

Это не замена внутриигровым подсказкам и не полный дамп каждой строки каталога оружия — полный каталог живёт в репозиторной wiki и собирается из балансных таблиц.
