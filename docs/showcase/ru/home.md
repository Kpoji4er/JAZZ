## Как читать

В обычном интерфейсе JAZZ **нет точного процента попадания**: силу эффекта показывают `+` и `−`. Точные проценты доступны только с modding/debug tools.

Правила и роли — на страницах витрины. Полные таблицы статов по семействам публикуются сюда же из generated `docs/wiki/weapons/` (CSV → генератор → wiki).
