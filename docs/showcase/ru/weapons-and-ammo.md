# Оружие и компоненты

## Тир и под-тир

**Тир** — заметный силовой диапазон внутри класса. Большой тир поднимает суммарную боевую ценность, но не обязан качать каждый отдельный стат.

**Под-тир** упорядочивает близкие варианты (магазин, темп, дальность, надёжность, модули) без скачка силы большого тира.

`UNIQ` — уникальный вариант. Предмет без тира — квестовый, технический или ещё не классифицированный.

## Как читать характеристики

| Поле | Смысл |
| --- | --- |
| Урон | Базовый урон одной пули до брони и прочих эффектов. |
| Пробитие | Класс против брони 1–5; патрон добавляет класс и дробную поправку (десятые). |
| Маг. | Ёмкость магазина. |
| ОД выстрел / перезарядка | Темп атаки и цена обслуживания. |
| Прицел | Число кликов × польза клика. |
| BDR / дальность | Конец эффективной зоны / физический предел выстрела. |
| Кучность | Как держится точность после эффективной зоны (смотреть вместе с BDR и дальностью). |
| Отдача | Тяжесть потери точности последующих пуль; меньше — легче очередь. Масса, габарит и темп отличают платформы одного калибра (у ПП компакт/высокий RPM сыплется сильнее, чем тяжёлый низкотемповый). |
| Режимы | Одиночный, очередь, авто и специальные действия. |

Стат `Handling` удалён из оружия и UI.

## Ресурс и обслуживание
Обычный ремонт восстанавливает текущий ресурс, но не возвращает утраченный предел надёжности. Обычные **Запчасти** в «Ремонте предметов» считаются по **проценту состояния** (порядка 1 шт. на ~5% починки), а не по огромному абсолютному ресурсу ствола. Для работ со стволом нужны **Ствольные запчасти**; при установленном съёмном прицеле — ещё и **Детали прицелов**. Разбор оружия даёт обычные **Запчасти** (по `ScrapParts` оружия) в сумку отряда; при удачном броске Mechanical можно дополнительно получить **Ствольные запчасти** в объёме install-cost ствола (обычно 1–3), а не цены модификации. В карточке оружия показывается эффективный шанс клина: он учитывает **надёжность самого оружия** (шкала ~5…95; при **95** даже плохие патроны не дают базового клина) и патроны, но при нормальном состоянии не превышает 10%. Текущее состояние и навсегда потерянный предел ресурса добавляют риск мягкими ступенями (полный худший износ + половина второго); MP40 даёт примерно 5% / 6% / 10% при 100% / 90% / 80% состояния, mid-износ у надёжного ствола — порядка ~10% сухо / ≤~20% под дождём, а **100%** только при полном разрушении. Механик снижает риск. Неудачный разклин мерком может срезать предел на 1–3%; NPC/ИИ снимают клин без такого износа. Съёмные обвесы при успешном снятии попадают в инвентарь; в заголовке видно, к какому оружию подходит модуль (включая магазины), а при наведении или перетаскивании подсвечивается совместимое оружие. Установка — кабинет или перетаскивание (Mechanical ≥30, ГП ≥40 — лучший в отряде). Провал снятия режет max на 1%; на изношенном оружии модуль может **сломаться** (прицел → Детали прицелов). **Интегрированный глушитель** (ПБ, Вал, MP5SD и т.п.) — часть оружия: не снимается и не выпадает при разборке.

## Дозарядка по патрону
Трубчатые дробовики, двустволки и револьверы: с пустого оружия используйте обычную перезарядку. Если в оружии уже есть патрон, та же кнопка становится **«Дозарядить»** и добавляет ровно один патрон за округлённую вверх долю полной цены (минимум 1 ОД). AA12 и USAS-12 с отъёмными магазинами сохраняют полную перезарядку.

**12-й калибр:** тип патрона задаёт пакет дробин — картечь ≈9, дробь/соль ≈20; пуля — один снаряд.

## Одноразовые гранатомёты
**M72 LAW** — один встроенный выстрел: его нельзя перезарядить или отремонтировать. После любого состоявшегося пуска, включая mishap, пусковая пропадает из инвентаря, а на земле остаётся только видимая пустая труба. **RPG-7** остаётся многоразовой пусковой и заряжается отдельными выстрелами.

## Компоненты

- **Оптика** — меняет специализацию оружия: клики, сдвиг зоны и AimAccuracy% **после** достаточного aim; сильная оптика мешает вблизи даже на snap; плоского бонуса CTH нет.
- **Коллиматоры** — эффективность ↑ vs irons: MinAim + −1 MaxAim + CloseRange soft; AimAccuracy% 120→160 с aim≥1 (~+20% CQB на топе); overwatch без AA% (Open/Pistol — **2** OW). **Eotech** — T4 (135 + mid OW).
- **Боевые прицелы** (2–4×) — специализация **mid**; AimAccuracy% 125→155 с AimLevel; мягкий near; без +ShotAP/crit. ACOG раньше ПСО на неполном aim; на полном aim ПСО ≈ ACOG.
- **Длинная оптика** — баф **max aim** (+ дальняя зона): T1 винтаж (ПУ/2×, AA% ~110); T2 ПСО (AA% 155 @ AimLevel 3); T3+ 6×…10× (лёгкий AA% 115→125). ShotAP, crit, near.
- **Ночные** — dark + near/OW.
- **Стволы** — эффективная дистанция: короткий лучше вблизи (−BDR, near↑, отдача↑); длинный лучше вдали (+BDR, near-tax, отдача↓); R только ±1.
- **Дульные устройства** — компенсатор = отдача; глушители = тишина + StealthKill↑ с тиром (цена Grouping/Rel/Jam, без Recoil); пламегаситель M2/M3 = Recoil + StealthKill, звук не глушит; choke = паттерн дроби. Дальность с дула не двигается.
- **Сошки** — один `Bipod`: prone CTH+10 и +1 выстрел до отдачи лёжа (Under-варианты — то же).
- **Side** — фонарь = темнота + свет (вкл/выкл); тактик = свет + OW/Mark; лазер = CTH с лимитом дистанции и спадом после 5 клеток; UV = ночной лазер + стелс.
- **Приклады** — Normal = дефолт без модов; Heavy Recoil−5+AimAccuracy%; Light≡Unfolded Recoil+2 (Light без fold); сложенный/без = ShootAP−1 + Recoil+5 + AA↓ + OW+2.
- **Рукояти** — мелкие и дешёвые: вертикальная = Recoil−1 (контроль очереди); тактическая / обмотка = CloseFactor+5 вблизи; эрго = AimAccuracy 105%.
- **Магазины** — число на магазине означает точную ёмкость: маленький = меньше патронов + Reload**−1**/Rel↑; увеличенный = больше патронов + Reload**+1** (без Rel/AA); большой = Reload**+2** + Rel−/AA−.
