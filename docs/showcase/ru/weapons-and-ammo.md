# Оружие и компоненты

## Тир и под-тир

**Тир** — заметный силовой диапазон внутри класса. Большой тир поднимает суммарную боевую ценность, но не обязан качать каждый отдельный стат.

**Под-тир** упорядочивает близкие варианты (магазин, темп, дальность, надёжность, модули) без скачка силы большого тира.

`UNIQ` — уникальный вариант. Предмет без тира — квестовый, технический или ещё не классифицированный.

## Как читать характеристики

| Поле | Смысл |
| --- | --- |
| Урон | Базовый урон одной пули до брони и прочих эффектов. |
| Пробитие | Работа против более защищённой цели. |
| Маг. | Ёмкость магазина. |
| ОД выстрел / перезарядка | Темп атаки и цена обслуживания. |
| Прицел | Число кликов × польза клика. |
| BDR / дальность | Конец эффективной зоны / физический предел выстрела. |
| Кучность | Как держится точность после эффективной зоны (смотреть вместе с BDR и дальностью). |
| Отдача | Тяжесть потери точности последующих пуль; меньше — легче очередь. |
| Режимы | Одиночный, очередь, авто и специальные действия. |

`Handling` в текущей точности не участвует.

## Компоненты

- **Оптика** — клики, сдвиг эффективной зоны, overwatch; сильная оптика может мешать вблизи; плоского бонуса CTH «за факт оптики» нет.
- **Стволы** — дальность, BDR, кучность, урон, темп, надёжность.
- **Дульные устройства** — шум, отдача, надёжность, скрытный огонь.
- **Сошки / опора** — удержание очереди в стойке или после развёртывания.
- **Приклады и рукояти** — темп, отдача, режимы, мобильность.
- **Магазины** — ёмкость и иногда цена перезарядки.

Полный каталог по тирам и список компонентов — в репозитории (`docs/wiki/weapons/`), числа собираются из канонических CSV, а не правятся руками на витрине.
