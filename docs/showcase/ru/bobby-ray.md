# Bobby Ray

[Обзор](home.md) · [Оружие и патроны](weapons-and-ammo.md) · [English](../en/bobby-ray.md)

Почтовый магазин в PDA. В JAZZ — **пять** тиров unlock; restock и цены зависят от разницы между тиром предмета и текущим unlock.

## Unlock

| Тир | Когда открывается |
| ---: | --- |
| 1 | Открытие магазина |
| 2 | ≥2 шахты |
| 3 | World Flip |
| 4 | World Flip + ≥4 шахты |
| 5 | World Flip + ≥5 шахт |

## Витрина

- Оружие / броня / обвесы / specialty-медицина / взрывчатка: чаще текущий unlock; выше unlock — редко и дорого (~**×3** за шаг вверх; дешевле, если тир ниже).
- Патроны: более старые пачки restockятся **чаще** по мере unlock; **Poor** вытесняется и с unlock **4+** не появляется.
- Staples (Meds, Parts, IFAK, Medkit, инструменты, запчасти ствола/прицела): с unlock **1**, без наценки за тир.
- Обвесы во вкладке **Other**: Optics · Magazines · Muzzle · Side · Underbarrel · Bipod.

Без Bobby кампания проходима; магазин — ресапплай, не «купить конец игры».
