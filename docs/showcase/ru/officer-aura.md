# Командная аура

[К обзору](home.md) · [Юниты Легиона](legion-units.md) · [Перки](perks.md) · [English](../en/officer-aura.md)

В бою у AI-офицеров (Легион, повстанцы и др.) виден статус **Командная аура**; у союзников рядом — **Под влиянием ауры**. В тултипе — **текущий приказ**. Игрок приказ не выбирает: офицер сам меняет его по обстановке.

## Радиус

| Офицер | Клетки |
| --- | ---: |
| Сержант / Leader | **15** |
| Лейтенант | **25** |
| Капитан / наёмный капитан / именные командиры (напр. **Призрак**) | **вся карта** |

Вне радиуса или после смерти командира влияние снимается. При нескольких офицерах побеждает больший радиус.

## Приказы

| Приказ | Когда | Эффект для игрока |
| --- | --- | --- |
| **Держать линию** | ~13–23 клетки до врага | Обычные роли отряда |
| **Давить** | враг ≤ **12** | Скауты чаще штурмуют |
| **Охват** | враг ≥ **24** | Штурм чаще уходит во фланг |
| **Отход** | тяжёлые потери | Жмутся к укрытию |
| **Сосредоточить огонь** | виден враг ≤40% HP | Чаще добивают эту цель |
| **Занимать дома** | город / здания | Бой из помещений |
| **Спрятаться** | дальняя перестрелка, без стелса | Укрытие, без натиска |
| **Скрыться** | ночь/туман **или** дальняя перестрелка + стелс | Пытаются стать **Hidden** |
| **Низкая видимость — держать** | ночь/туман без массового стелса | Осторожный hold |

Нет ручной кнопки приказа. Офицер не pathfind’ит за всех — только стиль боя. MG/тяжёлые чаще на своих ролях.
