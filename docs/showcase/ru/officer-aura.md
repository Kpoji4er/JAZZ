# Командная аура

[К обзору](home.md) · [Юниты Легиона](legion-units.md) · [Перки](perks.md) · [English](../en/officer-aura.md)

В бою у AI-офицеров виден статус **Командная аура**; у союзников рядом — **Под влиянием ауры**. В тултипе — **текущий приказ** и его небольшой эффект; у **Сосредоточить огонь** написано, **по кому**. Игрок приказ не выбирает: офицер сам меняет его по обстановке и со временем пробует другие (один приказ «устаёт»).

## Радиус

| Офицер | Клетки |
| --- | ---: |
| Сержант / Leader | **15** |
| Лейтенант | **25** |
| Капитан / наёмный капитан / именные (напр. **Призрак**) | **вся карта** |

Вне радиуса или после смерти командира влияние снимается. При нескольких офицерах побеждает больший радиус.

## Приказы

| Приказ | Когда | Эффект |
| --- | --- | --- |
| **Держать линию** | обычная дистанция | роли по умолчанию; **+2 CTH** |
| **Давить** | враг ≤ **12** | скауты штурмуют; **+1 ОД** |
| **Охват** | враг ≥ **24** | фланг; **+2 CTH** |
| **Отход** | ≥2 убитых и ≥30% отряда | укрытие; **−5 CTH** по ним |
| **Сосредоточить огонь** | снайпер / MG / близко / раненый | бьют **именно эту** цель; в тултипе видно **кого**; **+5 CTH** |
| **Занимать дома** | город | бой из зданий; **+2 CTH** |
| **Занять высоты** | холмы | high ground; **+2 CTH** |
| **Спрятаться** | дальняя перестрелка | укрытие; **−3 CTH** по ним |
| **Скрыться** | ночь/туман или стелс | **Hidden** |
| **Низкая видимость — держать** | ночь/туман без стелса | hold; **+2 CTH** |

Если в отряде нет снайпера / пулемётчика, командир **аурой** назначает одного бойца с оптикой/болтом или ПП/AR. При **Давить** назначает одного штурмовика (`pusher`) в радиусе — не весь отряд. Ракетчики держатся сзади. **Миномётчики** остаются на улице — из помещения миномёт не бьёт.

На ходе врага поддержка действует **раньше** штурма: светилки и дымовая завеса, развёртывание пулемёта, потом линия, потом нажим. Дым за ход кидает **один**; фаеров может быть несколько. Обычные гранаты: **Первая кровь** — **1** полный бросок (следующий слабее), **Коммандос** — **3** полных, **Миссия невыполнима** — без лимита.
