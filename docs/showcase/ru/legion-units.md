# Юниты Легиона

[К обзору](home.md) · [Легион на стратегии](legion-strategy.md) · [Кампания на Эрни](ernie-campaign.md) · [English](../en/legion-units.md)

## Две оси сложности

У Легиона в JAZZ **две независимые** шкалы:

1. **Класс юнита T1–T4** — кто стоит в отряде (stats, роль, AI, корневой пресет). Живой боец **не превращается** в следующий класс mid-fight: в отряд просто спавнят более высокий ID.
2. **Campaign gear tier** (`JAZZ_Legion_Tier`) — какой пул оружия/брони/патронов доступен при генерации лута. Растёт с числом **ваших** секторов; при смене тира экип Легиона может пересобраться.

На стратегии роли отрядов (гарнизон, патруль, QRF…) — отдельно: [Легион на стратегии](legion-strategy.md).

## Семейства (38 классов)

Шесть линий + рекрут для вербовщика:

| Семейство | От / до (примеры имён) | Роль |
| --- | --- | --- |
| Штурм | Головорез → … → Палач | Stormer / demolitions |
| Стрелки (Front) | Стрелок → … → Наемник / Наемник снайпер | Marksman / soldier / medic |
| Фланкеры | Дозорный → … → Рейнджер | Recon |
| Пулемётчики | Пуляло → … → Наемник Пулеметчик | Heavy MG |
| Командиры | Бригадир → … → Мастер | Commander (офицерская плотность в отрядах) |
| Тяжёлые | Ракетчик → Гранатомётчик → Миномётчик | Artillery |

### Штурм (имена)

T1 Головорез / Гренадёр / Громила → T2 Грабитель / Штурмовик / Пироман → T3 Каратель / Череполом → T4 Палач.

### Стрелки

T1 Стрелок / Костоправ / Мародёр → T2 Засадник / Налётчик / Охотник → T3 Снайпер / Ветеран → T4 Наемник / Наемник снайпер.

### Фланкеры

T1 Дозорный → T2 Скаут / Застрельщик → T3 Разведчик / Следопыт → T4 Рейнджер.

### Пулемёты

T1 Пуляло → T2 Пулемётчик / Коммандо → T3 Подавитель → T4 Наемник Пулеметчик.

### Командиры

Бригадир → Командир → Советник → Мастер. Для T4-отрядов на стратегии нужен **MercenaryCaptain**; офицеры садятся по плотности (порядка Sergeant/8, Lieutenant/15–20, Captain/30 бойцов).

### Артиллерия

Ракетчик → Гранатомётчик → Миномётчик.

## Gear tier по секторам

Стартовое значение тира снаряжения — **11**. Дальше (по числу секторов под вами):

| Ваших секторов | Tier |
| ---: | ---: |
| 0–1 | 11 |
| 2 | 12 |
| 3 | 13 |
| 4–8 | 21…25 |
| 9+ | 31…33 |

Выше tier → тяжелее допустимый лут у новых/пересобранных легионеров. Класс T1 с высоким gear tier — всё ещё «головарез», но уже с более злым обвесом.

## Цены (стратегия)

Ориентир `$` за голову в генераторе: линия **500 / 1000 / 2000 / 3500**, специалист **800 / 1500 / 2800 / 4500**, лидер **800 / 1500 / 2500 / 4000** по ступеням T1–T4.
