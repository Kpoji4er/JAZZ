# Боевые действия

## Откуда берётся кнопка

Атака появляется, когда одновременно:

1. оружие физически поддерживает режим;
2. класс и состояние оружия допускают действие;
3. у персонажа есть нужный перк или персональная способность (если требуется);
4. хватает ОД, патронов и выполнены условия стойки/развёртывания.

Перк может открыть действие, изменить ОД, число пуль, подавление или контроль отдачи. Влияние на точность идёт через тот же расчёт, что у обычной атаки.

## Базовые режимы

| Действие | Суть |
| --- | --- |
| Одиночный | Один прямой выстрел, без серии отдачи. |
| Очередь | Короткая очередь; первая пуля обычная, дальше — retention. |
| Автомат | Длинная очередь: плотность ценой боезапаса и накопленной отдачи. |
| Пулемётная очередь | Базовая тяжесть отдачи действия снижена; опора всё равно критична. |
| Дробь / дробовая серия / два ствола | Зональный расчёт, не одна нарезная пуля. |
| Overwatch | Контроль конуса; каждый interrupt считается из фактической позиции. |
| Pin Down | Удержание цели под угрозой реакции (не гарантия попадания). |
| Mobile Shot / Run and Gun | Выстрел или пакеты во время/после движения. |
| MG Setup | Разворачивает позицию; сам не стреляет. |

## Примеры классовых техник JAZZ

| Техника | Класс | Что даёт |
| --- | --- | --- |
| Fanning | револьвер | быстрая веерная серия с высокой тяжестью отдачи |
| Bullseye | снайперская | дорогой подготовленный выстрел в голову |
| SMG Storm | автопистолет | очень плотная ближняя серия с сильной отдачей и подавлением |
| Mozambique | пистолет | два в корпус + финальный в голову, у каждого свой CTH |
| Zipper | ПП | короткие очереди снизу вверх по цели |
| Double Tap | пистолет | дешёвая контролируемая пара |
| Salvo | боевая винтовка | мощная быстрая пара |
| Controllable Burst | ШВ / ЛП | короткая очередь, где первые две пули держат исходный CTH |
| Mobile Shotgun | дробовик | сближение, затем зональный выстрел |
| MG Suppression | пулемёт | две подавляющие очереди по одной зоне |

Полная таблица ID и edge-cases — в репозиторном `docs/wiki/combat-actions.md`.
