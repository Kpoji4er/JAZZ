## How to read this

In the normal JAZZ UI there is **no exact hit chance percent**: effect strength is shown with `+` and `−`. Exact percentages appear only with modding/debug tools enabled.

The full per-tier weapon catalog and machine tables live in the repository (`docs/wiki/`, `docs/technical/weapons/`). This showcase explains rules and roles; it does not duplicate every catalog row.
