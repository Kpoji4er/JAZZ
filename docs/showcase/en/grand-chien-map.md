# Grand Chien map

[Overview](home.md) · [Ernie campaign](ernie-campaign.md) · [Русский](../ru/grand-chien-map.md)

With the maps package, the campaign uses an **expanded** Grand Chien: grid **A–P** through column **32**, start sector **M1**. The vanilla A–L×20 layout is not used here.

Demo scope is **Ernie Island**; mainland data exists, but a full country playthrough is not promised. Check the in-game satellite view for the art.

## Familiar places → new sector IDs

| Place | Was | Now |
| --- | --- | --- |

| Fort L'Eau Bleu | H4 | **I7** |

Emerald Coast on Ernie is **J7**. Diamond Red is **A4**.

## Regions

- **Ernie** — start M1, hub I5, fort I7, rebel base L1.
- **Pantagruel** — slums/downtown around E15–E16.
- **Fleatown** — jungle port (H18–H19 area).
- **Port Cacao** — city and docks around N12–N13.
- **Landsbach** — A25–A26.

Ernie sector list: [Ernie campaign](ernie-campaign.md).
