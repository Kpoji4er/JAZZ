# What is JAZZ

[Overview](home.md) · [Русский](../ru/about.md)

## In short

**JAZZ** is a suite overhaul for *Jagged Alliance 3*: combat math, weapons and components, tactical and strategic AI, units, maps/content, and UI — shipped as four mod packages that load together.

| Package | Role |
| --- | --- |
| `jazz` | Core code, items, effects, UI |
| `jazz_assets` | Models, materials, textures |
| `jazz-maps` | Maps, quests, dialogue, sectors |
| `jazz-units` | UnitData, AI archetypes, squads, progression |

## What you will notice in play

- Chance to hit is shown with `+` / `−`, not a raw percent (unless debug tools are on).
- Eleven distinct firearm classes with clear combat roles; tiers compare power *inside* a class.
- Class and signature combat actions on top of vanilla fire modes.
- On Ernie, Legion squads show **roles** and **tasks** on the satellite map (garrison, patrol, recruiters, tax collectors, QRF, and more).

## What this wiki is

A bilingual **showcase**: aspects of the mod with concrete player-facing rules. It is published from the repository and updated when those rules change.

It is not a substitute for in-game tooltips, and it does not list every weapon row — that catalog lives in the repo player docs and is generated from balance tables.
