# Архитектурные решения JAZZ

Здесь хранятся долгоживущие решения, которые объясняют архитектурный выбор и не должны теряться после закрытия конкретной спецификации.

Формат имени: `ADR-NNNN-short-title.md`.

Минимальные разделы ADR:

- статус и дата;
- контекст;
- принятое решение;
- альтернативы;
- последствия;
- связанные specs и системы;
- условия пересмотра.
