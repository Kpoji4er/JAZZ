# ADR-0002: technical-документация и игроковая wiki

Статус: **принято**

Дата: **26 июля 2026 года**

## Контекст

Один документ не может одинаково хорошо служить current-state контрактом реализации, инструкцией разработчику, справочником игрока и машинным каталогом оружия. Игроку не нужны load order, generated-data provenance и внутренние поля, а разработчику нельзя опираться на упрощённое описание интерфейса.

## Решение

- `docs/technical/` является источником истины по фактически загруженной реализации, публичным ID, формулам, generated data, совместимости и проверкам.
- `docs/wiki/` описывает наблюдаемое игроком поведение, роли классов, боевые действия, интерфейс и контент понятным языком.
- Канонические оружейные числа и тиры хранятся в `docs/technical/weapons/data/*.csv`.
- `docs/wiki/weapons/*.md` генерируются `scripts/docs/weapons-docs.mjs`; вручную их не редактируют.
- Отключённое оружие с `catalog_status = excluded_disabled`, включая `AR15`, `M4Commando` и базовый `MP5`, не публикуется в игроковом каталоге.
- Человекочитаемые wiki-страницы могут ссылаться на stable ID для поиска и помощи агентам, но не выдают внутренние implementation details за игровое правило.

## Альтернативы

- Единый смешанный каталог отклонён: он перегружает игрока и размывает current-state контракт.
- Только technical-документация отклонена: она не заменяет игроковую wiki.
- Ручное копирование оружейных таблиц отклонено: оно неизбежно расходится с каноническими CSV.

## Последствия

- Изменение заметной игроку механики требует синхронного обновления technical и профильной wiki-страницы.
- Изменение оружейных чисел или компонентов идёт через CSV и повторную сборку wiki.
- Документационный аудит проверяет внутренние ссылки обоих слоёв.
- Wiki не является доказательством runtime-проверки; уровень evidence остаётся в spec и technical testing.

## Условия пересмотра

Решение пересматривается, если wiki переносится во внешний движок, появляется другой канонический каталог или generated pages перестают воспроизводимо собираться из CSV. Публичная GitHub Wiki-витрина описана отдельно в ADR-0003 и не заменяет `docs/wiki/`.
