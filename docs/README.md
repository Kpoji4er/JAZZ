# Документация JAZZ

Сейчас документация разделена на:

- `docs/technical/` — техническая часть: архитектура, источники данных, runtime, формулы, совместимость, тестирование.
- `docs/glossary.md` — единый глоссарий терминов для всех участников.

## Состояние

На данный момент `docs/wiki/` временно удалена для последующей пересборки. Пока ориентируемся на technical-описание как базовый источник.

## Как связаны разделы

- Техническая документация — source of truth по реализации.
- Игровые гайды временно снимаются в режим «только technical», до возврата `docs/wiki`.
- Любые изменения поведения закрываются вместе с технической документацией и проверочным отчётом.

## Статус среза

Документация отражает рабочий state по состоянию на 25 июля 2026 года.

`AGENTS.md` и project skills задают обязательный рабочий процесс и набор проверок для согласованного изменения кода и docs.
