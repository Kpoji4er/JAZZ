# Документация JAZZ

Документация разделена по аудитории. Выберите нужный маршрут:

| Раздел | Для кого | Что внутри |
|---|---|---|
| [Wiki по механикам](wiki/README.md) | Игроки и авторы гайдов | Как установить мод, как работают бой, оружие, броня, ранения, инвентарь, AI, погода, прогрессия и стратегия |
| [Техническая документация](technical/README.md) | Разработчики и моддеры | Архитектура четырёх пакетов, vanilla/CommonLib/JAZZ, runtime flow, файлы, IDs, формулы, совместимость, тесты и технический долг |

## Как связаны два раздела

- Техническая документация является источником истины по реализации.
- Wiki объясняет подтверждённое поведение с точки зрения игрока и не копирует внутреннее устройство без необходимости.
- Изменение, заметное игроку, обновляет обе стороны в одной задаче: техническую системную страницу и соответствующий wiki-гайд.
- Чисто внутренний refactor может затронуть только technical-раздел, если правила игры действительно не изменились.
- Код, generated data и документация обновляются как один согласованный change set: документация не откладывается на следующий коммит, а ещё не реализованное поведение не описывается как действующее.
- Если изменение проходит через несколько пакетов, связанные коммиты перечисляются вместе, чтобы реализация и описание оставались трассируемыми.

## Статус среза

Документация составлена 25 июля 2026 года по текущим working tree четырёх репозиториев:

- основной JAZZ: `5db078d`;
- assets: `f8c6c47`;
- maps: `9cae14e`;
- units: `d736d87`.

JAZZ всегда ориентирован на последнюю upstream-версию CommonLib. На дату среза это версия 1.11, build 1056, commit `1adf9f232680d3b011248d180fd0ad1e609a8e2c`. Значение является снимком аудита, а не pin зависимости.

Во время аудита в `jazz` и `jazz-units` уже присутствовали незакоммиченные пользовательские изменения. Документация описывает текущее рабочее состояние, не приписывая эти изменения отдельному релизу.

Исключение: первичный каталог характеристик оружия намеренно снят с последнего коммита JAZZ `5db078d`, чтобы отвергнутые плейтестовые изменения working tree не стали справочными данными. Балансовые тиры мигрированы из профильных вкладок Google Sheets и после миграции поддерживаются в [`technical/weapons/data/weapons.csv`](technical/weapons/data/weapons.csv).

## Постоянное сопровождение

Процесс закреплён в `AGENTS.md` и project skills:

- `.agents/skills/work-on-jazz-mod/SKILL.md`;
- `.agents/skills/document-jazz-systems/SKILL.md`;
- `.agents/skills/release-jazz-suite/SKILL.md`.

Новый или изменённый implementation-файл получает load-state и владельца в [техническом покрытии файлов](technical/systems/file-coverage.md). Новая или изменённая механика получает понятное описание в wiki.
