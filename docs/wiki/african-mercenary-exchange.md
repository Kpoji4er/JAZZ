# Африканская биржа наёмников (A.M.E.)

Отдельный сайт в PDA рядом с AIM: **African Mercenary Exchange** / **Африканская биржа наёмников**.

## Чем отличается от AIM

| | AIM / JAZZ AIM-мерки | A.M.E. |
| --- | --- | --- |
| Кто | Готовые профессионалы с именными перками | Местные бойцы с потенциалом роста |
| Сколько на витрине | Весь roster по фильтрам AIM | Около **15** доступных сразу из пула **60** |
| Ротация | Offline / contact rules AIM | Рынок обновляется примерно раз в **30** дней кампании |
| Цена | Выше | Ниже сопоставимого AIM; специалисты — самые дорогие на A.M.E. |

Найм идёт тем же чатом/контрактом, что у AIM. Наёмники A.M.E. **не** занимают лимит контактов AIM.

## Категории на сайте

- **Новобранцы / Irregulars** — новички и ополченцы, слабый стартовый кит.
- **Бойцы / Fighters** — уровень обычного полевого состава Легиона.
- **Закалённые / Hardened** — опытнее, лучше ствол (потолок вроде Type 56 у штурмовиков).
- **Специалисты / Specialists** — медики, инструкторы, снайперы, сапёры, механики (одна вкладка; роль видна на карточке).

Часть карточек со временем уходит с рынка (наняли другие, ушли в Легион, погибли) — серые, нанять нельзя. Ещё не появившиеся на бирже бойцы на сайте не показываются.

## Снаряжение и лица

У каждого слота свой фиксированный стартовый инвентарь (без случайного ролла найма) и свой портрет. Национальности — африканский пул (в т.ч. Grand Chien, ЮАР и новые страны с флагами на карточке).
