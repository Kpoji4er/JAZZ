# Стрелковые боевые действия

[К справочнику](README.md) · [Бой и точность](combat-and-accuracy.md) · [Классы оружия](weapon-classes.md)

## Откуда берётся действие

Кнопка атаки появляется из сочетания четырёх слоёв:

1. оружие физически поддерживает режим;
2. класс и текущее состояние оружия допускают действие;
3. персонаж имеет нужный перк или персональную способность;
4. хватает ОД, патронов и выполнены условия стойки/развёртывания.

Перк может открыть действие, изменить ОД, число пуль, подавление или контроль отдачи. Его влияние на точность проходит через тот же расчёт, что обычная атака. Наличие stable ID в таблице не означает, что кнопка доступна каждому персонажу.

## Базовые режимы и реакции

### Reload / «Дозарядить»
Для обычных магазинов Reload всегда меняет магазин целиком. У трубчатых дробовиков, двустволок и револьверов пустое оружие также показывает Reload, а неполное — **«Дозарядить»**: один патрон за `ceil(полная цена / ёмкость)`, минимум 1 ОД. Кнопка остаётся одной; при полной ёмкости она недоступна.

| ID | Что делает | Точность и отдача |
|---|---|---|
| `SingleShot` | Один прямой выстрел. | Общий CTH, отдачи серии нет. |
| `BurstFire` | Короткая очередь размером `BurstShots`. | Первая пуля обычная, следующие теряют точность по retention. |
| `AutoFire` | Длинная очередь размером `AutoShots`. | Высокая плотность ценой боезапаса и накопленной отдачи. |
| `AbakanBurst` | Фирменная двухпульная отсечка АН-94. | Вторая пуля защищена от обычного падения отдачи. |
| `AbakanAutoFire` | Автомат АН-94 со скоростной первой парой. | Первая пара защищена, затем действует обычный retention. |
| `DualShot` | Одновременная/парная атака из двух рук. | Каждый фактический выстрел рассчитывается отдельно. |
| `MGBurstFire` | Пулемётная очередь. | Базовая тяжесть отдачи действия снижена до `0.8 × Recoil`; опора остаётся критичной. |
| `Buckshot` | Один выстрел дробью. | Пакет дробин (картечь ≈9, дробь/соль ≈20); у каждой дробины тот же шанс, без отдачи между ними. |
| `BuckshotBurst` | Серия дробовых выстрелов. | Несколько патронов подряд, у каждого свой пакет дробин. |
| `DoubleBarrel` | Одновременный выстрел из двух стволов. | Два пакета дроби и двойной расход. |
| `AttackShotgun` | Общая кнопка выбора доступного режима дробовика. | Наследует цену и расчёт выбранного дочернего действия. |
| `Overwatch` | Контролирует конус и реагирует на движение/действия врага. | Каждый interrupt получает обычный расчёт из фактической позиции. |
| `PinDown` | Удерживает выбранную цель под угрозой реакции. | Собственный action factor поверх общего CTH; не гарантирует попадание. |
| `MobileShot` | Пистолетный выстрел после перемещения. | Дистанция и условия считаются из позиции выполнения. |
| `RunAndGun` | ПП стреляет пакетами во время движения. | Каждый пакет имеет собственную позицию и очередь. |
| `RunAndGun_Carbine` | Более дальний и редкий карабинный манёвр. | Меньше плотность, чем у ПП, но лучше дистанционный профиль. |
| `MGSetup` | Разворачивает пулемётную позицию. | Не стреляет сам; улучшает опору и контроль последующих очередей. |
| `CancelShot` | Реакцией срывает подготовленное действие цели по линии. | Снятие состояния требует фактического успешного воздействия. |
| `CancelShotCone` | Конусная версия срыва подготовленного огня. | Зональный расчёт по целям конуса. |

## Перки и служебные действия

| ID | Что делает |
|---|---|
| `Jazz_Perk_Buzz` | Пассивно увеличивает число пуль поддерживаемых burst/auto-действий на 50%; не повышает шанс первой пули. |
| `Jazz_Perk_Lynx` | Пассивно увеличивает обзор; отдельный подтверждённый CTH-бонус дальности пока не используется. |
| `FoldStock` / `UnFoldStock` | Переключает состояние складного приклада; следующая атака читает новые свойства компонента. |
| `FlashlightOn` / `FlashlightOff` | Переключает режим фонаря; эффект зависит от компонента и освещения. |
| `Unjam` | Устраняет задержку оружия; не является выстрелом и не рассчитывает CTH. |

Некоторые зарегистрированные действия остаются персональными, внутренними или ещё не имеют окончательного perk grant-path. Точный current-state по stable ID и известным расхождениям находится в [техническом справочнике](../technical/weapons/combat-actions.md).
