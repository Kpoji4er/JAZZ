# Текущие ограничения и совместимость

## Статус проекта

JAZZ находится в состоянии демо. Полностью поддерживается остров Эрни. Другие области могут содержать незавершённые карты, события, квесты, диалоги, составы врагов или баланс.

Это означает:

- не каждый существующий на диске сектор предназначен для текущего прохождения;
- часть будущего контента может быть видна в данных, но не подключена к кампании;
- найденный файл или предмет не обязательно является активной механикой;
- saves из более поздних областей могут вести себя непредсказуемо.

Ориентир по поддерживаемому острову: [остров Эрни — локации, квесты и враги](ernie-island-content.md).

## Язык

Текущий пользовательский контент ориентирован на русский язык. Английская локализация не считается полной. Если интерфейс показывает ID или пустую строку, сначала проверьте активную LocTable и язык игры.

## CommonLib

Поддерживается только последняя опубликованная CommonLib из официальной ветки `main`/Steam Workshop. Старые версии не являются отдельной целью совместимости.

После обновления CommonLib:

- убедитесь, что Steam действительно загрузил новую версию;
- перезапустите игру;
- проверьте новую игру и существующее сохранение;
- особенно внимательно проверьте AI, awareness, UI actions, Run and Gun, smoke и strategic squads.

## Сторонние моды

Официально не поддерживаются. Особенно рискованны:

- другие overhaul-моды;
- моды на CTH и combat actions;
- AI fixes, которые загружаются после JAZZ;
- новые inventory schemas;
- weapon packs, заменяющие те же IDs/classes;
- UI overhauls;
- campaign, sector и satellite modifications.

Два мода могут загрузиться без Lua error и всё равно тихо заменить функции или presets друг друга.

## Сохранения

Новая игра является эталонной проверкой. Existing saves могут содержать:

- предметы со старой схемой properties;
- старые slot assignments;
- прежние statuses и Will;
- squads/travel state другой версии;
- sector/quest state незавершённого контента.

Не удаляйте важное сохранение перед проверкой обновления. Сделайте отдельную копию средствами игры или Steam.

## Известные особенности

- Отдельный Vest slot сейчас не является полноценной активной пользовательской ячейкой.
- Логика «не слышать звуки через комнаты» присутствует как неактивная заготовка и не должна ожидаться в игре.
- Некоторые fix-файлы лежат в репозитории, но не загружаются metadata.
- Assets содержат legacy source paths, поэтому полная пересборка художественного pipeline может требовать дополнительных исходников.
- Сторонний standalone Lua linter не заменяет проверку игрой и Mod Editor.

## Как сообщать о проблеме

Полезный отчёт содержит:

- версии JA3 и последней CommonLib;
- список четырёх пакетов JAZZ;
- новую игру или existing save;
- сектор и фазу боя/стратегии;
- конкретный unit, item и action;
- воспроизводимые шаги;
- runtime log без публикации личных локальных путей.
