# Командная аура

В бою у AI-офицеров (Легион, повстанцы и другие с ролью командира) появляется статус **Командная аура**. Союзники рядом получают **Под влиянием ауры**. В тултипе видно **текущий приказ** — игрок его не выбирает, офицер меняет приказ сам по обстановке.

Радиус (в клетках от командира):

| Офицер | Радиус |
| --- | ---: |
| Сержант / keyword Leader | **15** |
| Лейтенант | **25** |
| Капитан / наёмный капитан | **вся карта** |

Вне радиуса или после гибели командира влияние снимается. Если офицеров несколько, действует старший (больший радиус).

## Приказы

| Приказ | Когда обычно | Что чувствуется в бою |
| --- | --- | --- |
| **Держать линию** | Средняя дистанция (~13–23 клетки), нет особых условий | Отряд держит позицию / роль по умолчанию |
| **Давить** | Ближайший враг ≤ **12** клеток | Скауты чаще идут в штурм |
| **Охват** | Ближайший враг ≥ **24** клеток | Штурмовики чаще уходят во фланг |
| **Отход** | Тяжёлые потери в отряде | Бойцы жмутся к укрытию, меньше лезут в рукопашную |
| **Сосредоточить огонь** | Виден сильно раненый враг (≤40% HP) | Отряд чаще добивает эту цель |
| **Занимать дома** | Город / много помещений, не в упорной схватке | Предпочитают позиции «линии», бой из зданий |
| **Спрятаться** | Дальняя перестрелка, свои уже потрёпаны, стелс недоступен | Уходят в укрытие, не лезут вперёд |
| **Скрыться** | Ночь / туман / пыль **или** дальняя перестрелка, если многие могут стелс | Пытаются войти в статус **Hidden** |
| **Низкая видимость — держать** | Ночь / туман / пыль, если стелс большинству недоступен | Осторожный hold, без агрессивного CQB |

Приоритет примерно сверху вниз по таблице «срочности»: сначала выживание (отход), потом низкая видимость / скрытность, добивание, укрытие, затем давление / дома / охват / линия.

## Что это не делает

- Нет кнопки «отдать приказ» у игрока.
- Офицер не водит весь отряд по клеткам — только подсказка стиля боя (роль / цель / попытка Hidden).
- Пулемётчики и тяжёлое оружие чаще остаются на своих архетипах.

Связано: командиры в каталоге юнитов Легиона; бейджи ауры на странице перков витрины.
