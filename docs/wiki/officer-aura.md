# Командная аура

В бою у AI-офицеров (Легион, повстанцы и другие с ролью командира) появляется статус **Командная аура**. Союзники рядом получают **Под влиянием ауры**. В тултипе видно **текущий приказ** и небольшой **эффект приказа** — игрок приказ не выбирает; офицер меняет его сам и со временем пробует другие приказы (один и тот же «устаёт»).

Радиус (в клетках от командира):

| Офицер | Радиус |
| --- | ---: |
| Сержант / keyword Leader | **15** |
| Лейтенант | **25** |
| Капитан / наёмный капитан / именные (напр. Призрак) | **вся карта** |

Вне радиуса или после гибели командира влияние снимается. Если офицеров несколько, действует старший (больший радиус).

## Приказы

| Приказ | Когда обычно | Что чувствуется + бафф |
| --- | --- | --- |
| **Держать линию** | Нет особых условий | Обычные роли; **+2 CTH** |
| **Давить** | Враг ≤ **12** клеток | Скауты чаще штурмуют; **+1 ОД** |
| **Охват** | Враг ≥ **24** клеток | Штурм чаще во фланг; **+2 CTH** |
| **Отход** | ≥2 убитых и ≥**30%** отряда | Жмутся к укрытию, не лезут вперёд; **−5 CTH** по ним |
| **Сосредоточить огонь** | Угроза: снайпер / пулемёт / кто подошёл близко / раненый | Чаще бьют эту цель; **+5 CTH** |
| **Занимать дома** | Город / много помещений | Бой из зданий; **+2 CTH** |
| **Занять высоты** | Холмы / перепад высот, не в упор | Тянутся на high ground; **+2 CTH** |
| **Спрятаться** | Дальняя перестрелка, свои потрёпаны | Укрытие; **−3 CTH** по ним |
| **Скрыться** | Ночь/туман **или** дальняя перестрелка + стелс | Пытаются стать **Hidden** |
| **Низкая видимость — держать** | Ночь/туман без массового стелса | Осторожный hold; **+2 CTH** |

Один приказ не висит весь бой: со временем его «вес» падает, офицер переключается на другие подходящие. **Отход** при реальных потерях почти не «устаёт».

## Роли в отряде

- Нет dedicated-снайпера, но есть боец с **оптикой / болтовкой** — командир **аурой** назначает одного «полуснайпера» (держит дистанцию под оптику).
- Нет пулемётчика, но есть **ПП / штурмовик** — командир назначает одного «как MG» (чаще Overwatch).
- Приказ **Давить** / штурм: командир назначает **одного** `pusher` в радиусе (остальные скауты не все лезут в Assaulter).
- Назначения только **в радиусе ауры**; приоритет ролей: полуснайпер → псевдо-MG → pusher.
- **Ракетчики / тяжёлые** стараются держаться **позади** линии.
- **Миномётчики** не садятся в помещения: `Bombard` изнутри невозможен, поэтому они ищут открытую позицию сзади.
- Снайперы с оптикой выбирают дальность с учётом кратности (не лезут в упор под длинный прицел).

## Что это не делает

- Нет кнопки «отдать приказ» у игрока.
- Офицер не водит весь отряд по клеткам — стиль боя, цель Focus Fire, высоты/укрытие.

Связано: командиры в каталоге юнитов Легиона; бейджи ауры на странице перков витрины.
