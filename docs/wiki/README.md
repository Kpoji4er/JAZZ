# Wiki JAZZ: гайд по механикам

Этот раздел объясняет мод с точки зрения игрока. Здесь нет необходимости разбираться в Lua, Mod Editor или порядке загрузки файлов.

JAZZ — большой tactical overhaul для Jagged Alliance 3. Он меняет не отдельные предметы, а связанную модель боя: оружие, точность, очереди, броню, ранения, волю, инвентарь, AI, видимость, погоду, составы противников и стратегическую карту.

> Текущая версия является демо. Полностью поддерживается остров Эрни; контент за его пределами может быть незавершён. Интерфейс и тексты мода рассчитаны на русский язык.

## Главная идея мода

В JAZZ хорошее оружие само по себе не гарантирует результат. Важны роль бойца, дистанция, положение, видимость, состояние снаряжения и выбранный режим огня. Успешный отряд комбинирует специализации:

- точный стрелок использует дальность и прицеливание;
- штурмовик управляет средней дистанцией и очередями;
- пулемётчик подавляет и отнимает у противника волю;
- боец ближнего боя использует мобильность, пистолеты, ПП и дробовики;
- специалист по взрывчатке контролирует зоны и укреплённые позиции;
- разведчик работает с ночью, камуфляжем и обнаружением.

## Как пользоваться wiki

Каждый гайд сначала объясняет правило, затем даёт практические выводы. Точные формулы, IDs и файлы вынесены в [техническую документацию](../technical/README.md). Если wiki и техническая страница расходятся, исправлению подлежат обе: реализация подтверждается technical-разделом, а пользовательский смысл — wiki.
