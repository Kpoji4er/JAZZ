## Как читать этот справочник

Обычный интерфейс JAZZ намеренно не показывает точный процент попадания: силу положительного или отрицательного эффекта передаёт разное количество `+` и `−`. Точные проценты и множители доступны только с включёнными modding/debug tools. Для гранат и гранатомётов цвет зоны поражения и дуги броска, а также индикатор mishap показывают риск провала — см. [Бой и точность](combat-and-accuracy.md).

Тиры и числовые характеристики в каталоге берутся из канонических таблиц документации. Большой тир должен заметно менять общую силу оружия; под-тир различает близкие варианты и не является скрытым дополнительным тиром.

Внутреннее устройство мода, формулы, stable ID и проверки находятся в [technical-документации](../technical/README.md).
