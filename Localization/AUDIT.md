# Аудит localization ID

Срез: 26 июля 2026 года. Проверены `items.lua` и Lua-пути из
`metadata.code` четырёх пакетов JAZZ. Dormant Lua учитывается отдельно;
`jazz-maps/Maps/` не обходился.

Источники сравнения:

- базовый русский `Game.csv`: 31 221 строка и столько же уникальных ID;
- приоритетный `jazz/Russian.csv`: 23 уникальных ID;
- JAZZ: 13 488 активных употреблений `T`, 9 032 активных ID.

- `jazz`: 155 ID;

Наиболее крупные группы повторно используют общие ID для названий,
описаний и подсказок разных боеприпасов, револьверов, пистолетов,
CharacterEffect и CombatAction. Например, ID `360885048478`,
`285060449915` и `865245516789` имеют по 13 разных текстов.

## Рабочий каталог перевода

`Strings.csv` содержит 8 477 строк, относящихся к JAZZ:

- 5 981 новых ID, отсутствующих в базовом `Game.csv`;
- 23 строки из более нового `Russian.csv`, имеющего приоритет;
- 1 489 строк пока требуют русского текста;
- 7 143 строки требуют английского текста;
- 177 строк нельзя переводить до устранения активной коллизии ID.

Заполненный `English` сохраняется при повторном запуске аудитора. Экспорт
`English.csv` блокируется, пока остаются пустые английские строки или
статусы `collision`.

## Проблемы текущего `Russian.csv`

Runtime-файл не изменялся. Его заголовок объявляет официальную
пятиколоночную схему, но 23 записи содержат дополнительные колонки старого
экспорта. Две строки имеют повреждённое CSV-экранирование, одна запись
многострочная. Аудитор восстанавливает все 23 ID для рабочего каталога, но
сам runtime-файл следует нормализовать отдельным контролируемым
Mod Editor/export round-trip.
