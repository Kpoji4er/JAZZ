# Локализация JAZZ

## Назначение

Вести перевод через рабочий каталог `Localization/Strings.csv`, а не через ручную
склейку runtime CSV. Использовать `scripts/localization/audit-localization.ps1`
как канонический парсер, аудитор и экспортёр.

Перед изменением каталога или экспортом прочитать
[`references/localization-contract.md`](references/localization-contract.md)
полностью.

## Выбрать режим

- Для инвентаризации, оценки стоимости перевода и поиска проблем запустить
  read-only аудит без `-UpdateCatalog`.
- Для синхронизации рабочего каталога запустить аудит с `-UpdateCatalog`.
- Для перевода изменять только ручные поля каталога.
- Для подготовки игрового файла экспортировать сначала во временный путь.
- Для замены runtime `Russian.csv` или добавления `English.csv` считать задачу
  изменением данных мода и подключить профильные project skills.

## Подготовить входные данные

1. Найти корень `jazz` и прочитать действующий `AGENTS.md`.
2. Проверить `git status --short` четырёх пакетов перед любыми записями.
3. Найти русский базовый `CurrentLanguage/Game.csv` и передать его через
   `-GameCsv`. Не сохранять абсолютный локальный путь в отслеживаемых файлах.
4. По умолчанию использовать корневой `Russian.csv` мода: аудитор уже считает
   его приоритетным источником.
5. Не просить отдельную английскую локализацию игры только ради `Text`:
   английский исходник уже содержится в русском `Game.csv`.

## Запустить аудит

Read-only:

```powershell
scripts/localization/audit-localization.ps1 `
  -GameCsv "<path-to-Russian/CurrentLanguage/Game.csv>"
```

Обновление каталога и отчёта:

```powershell
scripts/localization/audit-localization.ps1 `
  -GameCsv "<path-to-Russian/CurrentLanguage/Game.csv>" `
  -UpdateCatalog
```

Строгая проверка:

```powershell
scripts/localization/audit-localization.ps1 `
  -GameCsv "<path-to-Russian/CurrentLanguage/Game.csv>" `
  -Strict
```

Считать exit code `2` ожидаемым сигналом блокирующих коллизий или ошибок CSV, а
не поводом обходить проверку. Изучить `Localization/Collisions.csv` и сводку
аудитора.

Не обходить `jazz-maps/Maps/`, если пользователь прямо не назвал карту, сектор
или map patch. Аудитор намеренно работает с активными путями `metadata.code` и
ModItem-строками из `items.lua`.

## Редактировать перевод

В `Localization/Strings.csv` вручную менять только:

- `Russian`;
- `English`;
- `Notes`.

Остальные поля считать вычисляемыми и обновлять аудитором. Не удалять строку
только потому, что она кажется неиспользуемой: проверить `Status`, `Locations` и
потребителей во всех четырёх пакетах.

Сохранять ID как текст из цифр. Не преобразовывать его в число, scientific
notation, `Int64` или IEEE-754. Сохранять регистр и содержимое тегов,
placeholder-ов, управляющих последовательностей и переносов строк.

Не разбирать CSV через `Split(',')` и не собирать строки конкатенацией. Поля могут
содержать запятые, кавычки и CR/LF; `Russian.csv` также может иметь широкие или
повреждённые записи, которые аудитор восстанавливает терпимо и явно отмечает.

## Разрешить коллизии

Одинаковый ID с одинаковым исходным текстом считать повторным использованием.
Одинаковый ID с разными исходными текстами считать коллизией, даже если один из
текстов уже переведён.

Не выбирать перевод по догадке и не объединять разные строки в одну. Найти все
`Locations`, определить владельца ID и развести разные смыслы по уникальным ID.
Если исправление затрагивает Lua или generated data, остановить CSV-правку,
подключить `work-on-jazz-mod`, а для generated data также
`sync-jazz-generated-data`.

## Экспортировать runtime CSV

Экспортировать сначала во временный или явно указанный пользователем путь:

```powershell
scripts/localization/audit-localization.ps1 `
  -GameCsv "<path-to-Russian/CurrentLanguage/Game.csv>" `
  -ExportEnglishCsv "<temporary-path-to-English.csv>"
```

Для русского использовать `-ExportRussianCsv`. Не создавать неполный
`English.csv` с заглушками. Экспорт обязан остановиться, если выбранный язык
заполнен не полностью или любой ID имеет статус с `collision`.

Проверить у результата:

- первую строку `sep=,`;
- заголовок `ID,Text,Translation,VoiceActor,Context`;
- UTF-8;
- сохранность кавычек, запятых и многострочных полей;
- точное множество ID и отсутствие дублей с разными текстами;
- сохранность тегов и placeholder-ов относительно `SourceText`.

Сравнить экспорт с каталогом. Не заменять корневой runtime CSV автоматически.
Если пользователь просит включить файл в мод, выполнить предусмотренную проектом
generated-data/Mod Editor транзакцию и обновить техническую документацию в том
же change set.

## Отчитаться

Указать:

- число активных ID и строк каталога;
- `needs-russian`, `needs-english` и все виды коллизий;
- какие файлы обновлены или экспортированы;
- исключался ли `jazz-maps/Maps/`;
- какие проверки выполнены;
- что осталось блокирующим;
- проводилась ли только статическая проверка или также проверка в Mod Editor/игре.
