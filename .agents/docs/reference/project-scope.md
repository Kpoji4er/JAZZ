# JAZZ: проектный контур

## 1) Что это такое

JAZZ — мод из **4 пакетов**, которые работают как единый модовый комплект. Изменения могут жить в одном пакете, но их поведение и конфликты нужно видеть во всех.

## 2) Краткая матрица ответственности

| Репозиторий | Роль |
| --- | --- |
| `jazz` | Пакет логики, предметов, эффектов, UI-контента |
| `jazz_assets` | 3D и визуальные сущности: модели, материалы, текстуры, эффекты |
| `jazz-maps` | Карты/секторы/квесты/диалоги/сетапы AI для конкретных зон |
| `jazz-units` | UnitData, AI-архетипы, отряды, progression |

Перед тем как править, проверь, где живёт источник данных (владельца ID/таблицы/персоны). Не переносить ownership между репозиториями без явного архитектурного запроса.

## 3) Обязательные официальные источники

- <https://github.com/THQNordic/JaggedAlliance3Modding>
- `<JA3_ROOT>\ModTools\Src`
- `<JA3_ROOT>\ModTools\Docs\index.md.html`
- `<JA3_ROOT>\ModTools\Samples`
- <https://gitlab.com/injto4ka/ja3_commonlib>

`<JA3_ROOT>` — локальный путь на машине (`F:\...\Jagged Alliance 3` и т.п.), в Git не коммитится.

## 4) Где искать фактическую правду

1. Vanilla (`ModTools/Src`) — базовая сигнатура движка.
2. CommonLib (последняя upstream `main`) — текущая точка совместимости.
3. JAZZ — реализация мода.

Если есть расхождения, приоритет при принятии решения: **VAJA3 → CommonLib → JAZZ** по времени загрузки и реальному применению.

## 5) AI-first контур

С 25 июля 2026 JAZZ объявлен AI-first-проектом. Практически это означает:

- AI-агент для анализа/диагностики/первых проходов.
- Полный трассируемый diff с документацией.
- Решение по gameplay и балансу за владельцем проекта.

Обновлять `JAZZ` за счёт только удобства агента нельзя.

## 6) Имена и ограничения

- `Mod/<id>/...` ссылки только по необходимости и с документированием зависимости в `metadata.lua`.
- ID пакетов: `e6L4ECj`, `pDGDhr`, `FhNNYd`, `Dv3mFVN`, `JA3_CommonLib`.
- Не переименовывать `preset/entity/class/localization ID`, пока не проверены все 4 репозитория.

## 7) Экономия контекста для агентов

- Для всех задач начинать с `metadata.lua` + target ID/пути + narrow `rg`.
- Не открывать большие каталоги/файлы без прямой необходимости. Это особенно критично для `jazz-maps/Maps/`.
